# 라이츠 아웃 (Lights Out) 퍼즐 구현 계획서

## 개요
- **퍼즐 ID**: `lights-out`
- **카테고리**: `puzzle`
- **난이도**: `medium`
- **경로**: `/puzzle/lights-out`
- **학습 목표**: 프로그래밍 '이벤트' 개념과 연결 — 하나의 클릭(이벤트)이 주변에 반응(핸들러)을 일으키는 구조 체험

## 페이지 구성 (3페이지)

### 페이지 1: 룰 설명 (`/puzzle/lights-out`)
- **목적**: 게임 규칙을 직관적으로 이해시키기
- **구성 요소**:
  - 타이틀 + 소개 문구
  - 핵심 규칙 설명:
    - 격자판의 불(켜짐/꺼짐)이 있다
    - 셀을 클릭하면 자기 자신 + 상하좌우(십자)가 토글된다
    - 모든 불을 끄면 클리어
  - 인터랙티브 데모: 3×3 미니 보드에서 직접 클릭해보며 규칙 체험
  - "게임 시작" 버튼 → 게임 페이지로 이동

### 페이지 2: 게임 (`/puzzle/lights-out/game`)
- **목적**: 5단계 난이도로 퍼즐 풀기
- **난이도 구성**:
  | 단계 | 격자 크기 | 초기 켜진 불 수 | 설명 |
  |------|-----------|-----------------|------|
  | 1    | 3×3       | 적음 (3~4개)    | 입문 |
  | 2    | 3×3       | 보통 (5~6개)    | 연습 |
  | 3    | 4×4       | 적음 (4~5개)    | 확장 |
  | 4    | 4×4       | 보통 (7~8개)    | 도전 |
  | 5    | 5×5       | 많음 (10~12개)  | 마스터 |
- **구성 요소**:
  - 단계 선택 바 (1~5, 잠금/해제 표시)
  - 게임 보드 (동적 격자)
  - 이동 횟수 카운터
  - 리셋 버튼
  - 클리어 시 축하 연출 + 다음 단계 버튼
  - 단계별 잠금: 이전 단계 클리어해야 다음 단계 해제
- **게임 로직**:
  - 클릭 시 십자 토글 (자신 + 상하좌우)
  - 보드 경계 체크 (범위 밖은 무시)
  - 모든 셀이 꺼짐 → 클리어 판정
  - 풀 수 있는 퍼즐만 생성 (solvability 보장)

### 페이지 3: 수학적 원리 (`/puzzle/lights-out/math`)
- **목적**: 게임 뒤에 숨은 수학 설명
- **구성 요소**:
  - **이벤트와의 연결**:
    - 클릭 = 이벤트 발생
    - 십자 토글 = 이벤트 핸들러(반응)
    - 하나의 이벤트가 여러 대상에 영향 = 이벤트 전파
  - **XOR(배타적 논리합) 패턴**:
    - 같은 셀을 2번 누르면 원래대로 → 토글의 수학적 성질
    - 짝수 번 = 취소, 홀수 번 = 적용
  - **순서 무관 성질**:
    - 누르는 순서는 결과에 영향 없음 (교환법칙)
    - 각 셀을 "누를지 말지"만 결정하면 됨
  - **행렬과 연립방정식** (심화):
    - GF(2) 위의 선형대수로 풀 수 있음 (간단히 소개)
    - 인터랙티브 시각화: 버튼 누름 → 영향 패턴 행렬 보여주기

## 게임 로직 (`lightsOut.ts`)

### 핵심 함수
- `createBoard(size)`: 빈 보드 생성
- `toggleCell(board, row, col)`: 십자 토글 적용한 새 보드 반환
- `isSolved(board)`: 모든 셀이 꺼져있는지 확인
- `generatePuzzle(size, difficulty)`: 풀 수 있는 퍼즐 생성
  - 방법: 빈 보드에서 랜덤 셀을 N번 클릭하여 역으로 생성 (solvability 자동 보장)

### 난이도별 설정
```typescript
interface LevelConfig {
  level: number;
  size: number;
  clicks: number;  // 생성 시 랜덤 클릭 수
  name: string;
}
```

## 스타일 가이드
- 기존 프로젝트 라이트 테마 따름 (`--primary`, `--surface` 등)
- CSS Modules 사용
- 반응형: 768px, 480px 브레이크포인트
- 셀 상태 색상:
  - 켜짐(ON): `--primary` (#037dd6) 계열 밝은 색 + glow 효과
  - 꺼짐(OFF): `--surface` (#f2f4f6) 계열
  - 클릭 시: 짧은 pulse 애니메이션
