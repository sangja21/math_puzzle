# 코딩의 원리 - 이벤트(Event) 구현 계획서

## 개요
- **경로**: `/coding/event`
- **카테고리**: 코딩의 원리 → 이벤트 파트
- **학습 목표**: 언어 독립적으로 "이벤트"의 개념을 체험 — ~하면 ~한다 (트리거 → 반응)
- **방향**: 퍼즐(라이츠 아웃, 생명 게임)에서 체험한 이벤트 개념을 명시적으로 정리

## 탭 구성 (3단계)

### 탭 1: 일상 속 이벤트 (🔔 이벤트란?)
- **목적**: 이벤트 = "~하면 ~한다"라는 개념을 일상 비유로 이해
- **인터랙티브 데모**:
  - 일상 이벤트 카드 3~4개 (초인종, 알람, 신호등, 전화)
  - 카드를 클릭하면 → 트리거 발생 → 반응 애니메이션
  - 각 카드에서 "이벤트(트리거)"와 "핸들러(반응)" 매핑 표시
- **설명 패널**:
  - 이벤트 = 어떤 일이 발생하는 것
  - 핸들러 = 그 일이 발생했을 때 실행되는 동작
  - 프로그래밍에서도 동일: 클릭, 키 입력, 타이머 등

### 탭 2: 이벤트 실험실 (🧪 실험실)
- **목적**: 실제 브라우저 이벤트를 직접 발생시키고 로그로 확인
- **인터랙티브 데모**:
  - 이벤트 감지 영역 (큰 박스)
  - 이벤트 종류:
    - 클릭 이벤트 → "클릭됨! (x, y)"
    - 마우스 진입/퇴장 → "마우스 들어옴/나감"
    - 키보드 입력 → "키 눌림: A"
    - 더블클릭 → "더블클릭!"
  - 이벤트 로그: 실시간으로 발생한 이벤트 목록 표시 (최근 10개)
  - 이벤트 카운터: 각 종류별 발생 횟수
  - 클리어 버튼

### 탭 3: 이벤트 연결하기 (🔗 연결)
- **목적**: 이벤트에 다른 핸들러를 연결하는 체험
- **인터랙티브 데모**:
  - 왼쪽: 이벤트 소스 (버튼 3개: 빨강/초록/파랑)
  - 오른쪽: 반응 대상 (캐릭터/전구/소리 아이콘)
  - 드래그 또는 선택으로 이벤트-핸들러 매핑
  - 매핑 후 버튼 클릭 → 연결된 반응 실행
  - 블록코딩 미리보기: 만든 매핑을 Scratch 스타일 블록으로 보여줌

## 파일 구조

## 스타일 가이드
- 기존 function 페이지와 동일한 레이아웃 패턴
- 탭 네비게이션 (3탭)
- 설명 패널 + 인터랙티브 영역 2컬럼
- 반응형: 768px, 480px
