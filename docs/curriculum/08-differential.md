# 미분 — 롤러코스터의 속도

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 미분 — *롤러코스터의 속도* |
| **스토리 요약** | (※ 원문 확인 필요) 롤러코스터는 매 순간 속도가 다르다. *지금 이 순간* 의 속도를 어떻게 정의할까? — 평균변화율을 한없이 좁히면 순간변화율이 된다는 *극한*의 발상. |
| **핵심 수학** | 평균변화율 → 순간변화율 · 도함수 f'(x) · 접선의 기울기 · 극값(극대·극소) · 다항·삼각·지수의 미분 공식 |
| **학습 목표** | ① 평균변화율과 순간변화율의 차이 ② 접선 기울기 = 도함수 값 ③ f'=0 이 극값 후보 ④ "변화" 를 수학으로 잡는 *언어로서의 미분* 습득 |

## 관련 수학퍼즐 조사

### 사이트 내 연관 퍼즐
- `linear-function` — 기울기 = 미분의 *원형*. 본 단원에서 "직선의 기울기 = 그 직선의 어느 점에서나 같은 미분값" 으로 다시 만남.
- `quadratic-function` (구현 시) — 꼭짓점 = f'=0. 미분 도입의 첫 비자명 사례.
- `collatz` — 수열의 *변화* 와 약하게 연결 (이산 → 연속의 다리).
- `machin` — 급수와 미적분.

### 외부 클래식 퍼즐·사례
- **갈릴레이의 자유낙하** — 거리 ∝ t², 속도 = 미분 → 2t.
- **페르마의 극값법** (1636) — 미분 발견 *전* 의 극값 찾기.
- **뉴턴 vs 라이프니츠** — 미적분 발견의 역사.
- **롤러코스터 트랙 설계** — 곡률·가속도 = 미분의 미분.
- **주식 차트의 변화율** — 일상의 미분.
- **자동차 계기판 속도** — 위치의 미분.

## 구현 안건

### 안건 A — 표준 하네스 (곡선 위 점 이동 + 접선)
- **컨셉**: 곡선 위 한 점을 슬라이더로 이동 → 그 점에서의 *접선* 이 함께 그려짐. 접선의 기울기 = 도함수 값.
- **탐험기**: 함수 선택(이차·삼차·sin·exp), x 슬라이더, "할선 → 접선" 토글 — 두 점을 가까이 옮기면 할선이 접선으로 *수렴* 하는 애니메이션.
- **퀴즈**: (1) 평균변화율과 순간변화율의 차이? (2) f'=0인 점은 어디? (3) 다음 그래프에서 접선이 가장 가파른 곳?
- **코딩 탭**: 수치미분 의사코드 `(f(x+h) - f(x)) / h` (h → 0).
- **예상 공수**: 중 (할선→접선 애니메이션이 핵심).
- **장점**: 미분의 *정의* 인 극한 과정을 시각으로 잡음.
- **단점**: 책 스토리(롤러코스터)와 거리.

### 안건 B — 롤러코스터 속도계 (시뮬 중심)
- **컨셉**: 롤러코스터가 트랙(곡선)을 따라 달림. 캐릭터 옆에 *실시간 속도계* 가 미분값을 보여줌.
- **메인 동선**: 트랙(곡선) 선택 → 재생 시작 → 캐릭터가 트랙을 달리며 속도계가 변동. 가장 빠른 지점(가장 가파른 접선) 추측 게임.
- **트랙 편집기**: 사용자가 점을 찍어 곡선을 만들면 그 트랙이 *실제 가속도/속도* 어떻게 되는지 즉시 시뮬.
- **확장**: 가속도(2차 미분) 표시 — "G포스" 게이지로 가시화.
- **예상 공수**: 중~대 (캐릭터 애니메이션 + 트랙 편집기).
- **장점**: 책 스토리 100% 매칭, *움직임 = 미분* 의 직관이 강력.
- **단점**: 미분의 *수식 공식* 학습은 약함 — 별도 탭/페이지로 보강 필요.

### 안건 C — 극값 사냥 게임
- **컨셉**: 무작위로 생성된 곡선의 *모든 극대·극소점* 을 클릭으로 잡는 게임.
- **메인 동선**: 매 라운드 새로운 다항·삼각함수 그래프. 사용자가 봉우리·골짜기를 클릭. 빠르고 정확할수록 점수.
- **힌트 모드**: 도함수 그래프가 아래에 살짝 보임 — 0이 되는 곳이 정답이라는 *발견* 학습.
- **레벨 진행**: 1차→2차→3차→삼각함수→복합 함수 순.
- **예상 공수**: 중 (곡선 생성기 + 채점 로직).
- **장점**: 게임성 높음, 페르마의 극값법 직관 학습.
- **단점**: 책 스토리와 거리. 미분의 *정의* 자체는 약하게 노출.
