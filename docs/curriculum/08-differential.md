# 미분 — 롤러코스터의 속도

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 미분 — *롤러코스터의 속도* |
| **스토리 요약** | (※ 원문 확인 필요) 롤러코스터는 매 순간 속도가 다르다. *지금 이 순간* 의 속도를 어떻게 정의할까? — 평균변화율을 한없이 좁히면 순간변화율, 즉 *극한* 의 발상. |
| **핵심 수학** | 평균변화율 → 순간변화율 · 도함수 f'(x) · 접선의 기울기 · 극값 · 다항·삼각·지수의 미분 공식 |

## 교과 맥락

- **한국 정규 교과**: 미분 = **고등학교 수학Ⅱ·미적분** ([나무위키 — 미분](https://namu.wiki/w/%EB%AF%B8%EB%B6%84))
- **초등·중학교**: *변화율* 직관 자체는 가능 (예: "1시간에 5km 갔다 = 시속 5km")
- **결론**: 식·극한은 어려움. *움직이는 물체의 속도* 시각·체험은 초등도 가능.

## 학습 목표

1. 평균변화율 = "두 시점 사이 평균 빠르기" → 순간변화율 = "지금 이 순간 빠르기"
2. 곡선 위 한 점의 *접선의 기울기* = 그 순간의 변화율 = 도함수 값
3. f' = 0 인 곳이 극값 후보 — 가장 높거나 낮은 자리

## 관련 사이트 내 퍼즐

- `linear-function` — 기울기 = 미분의 *원형* (직선의 어느 점에서나 같은 미분값)
- (이차함수) — 꼭짓점 = f'=0
- `collatz` — 수열의 *변화* 와 약하게 연결

## 수학퍼즐 후보 조사

### 후보 1 — 곡선 위 점 + 접선 (탐험기) 🎯
- **퍼즐 정의**: 곡선 위 한 점을 슬라이더로 이동 → 그 점에서의 *접선* 이 함께 그려짐. 접선의 기울기 = 도함수 값.
- **풀이 흐름**: 함수 선택(이차·삼차·sin·exp), x 슬라이더, "할선 → 접선" 토글
- **선례**: [DerivativeCalculus.com](https://www.derivativecalculus.com/tangent-line-explorer.html), [GeoGebra Tangent Animation](https://www.geogebra.org/m/sVCRDDmA), Desmos. 표준 자산 다수.
- **초등 적합성 ★★**: 부분 적합. *접선* 개념 자체가 추상. 5~6학년 가능하나 *기울기* 직관은 단원 0(linear) 학습이 전제. 6학년 + 도움말이면 가능.

### 후보 2 — 롤러코스터 속도계 시뮬 🎢
- **퍼즐 정의**: 롤러코스터가 트랙(곡선)을 따라 달림. 캐릭터 옆 *실시간 속도계* 가 미분값을 보여줌. 가장 빠른 지점 추측 게임.
- **풀이 흐름**: 트랙(곡선) 선택 → 재생 시작 → 캐릭터가 트랙을 달림, 속도계 변동 → 가장 가파른 곳 클릭으로 추측
- **선례**: CK-12 물리 시뮬, Javalab 운동 시뮬, 뉴스페퍼민트 글. 롤러코스터 물리는 한국 자료 풍부.
- **초등 적합성 ★★★**: 추천. *움직임 + 속도계* 가 직관적. 3~6학년 가능. 책 스토리(롤러코스터) 100% 매칭. 식 불필요.

### 후보 3 — 자동차 속도-위치 그래프 🚗
- **퍼즐 정의**: 자동차가 도로를 달림. 사용자는 *위치 그래프* 와 *속도 그래프* 두 개를 본다. 위치 그래프의 *기울기* 가 속도임을 발견.
- **풀이 흐름**: 자동차 출발 → 두 그래프 동시 그려짐 → "위치가 가파른 곳에서 속도가 어떨까?" 발견
- **선례**: PhET *Moving Man*, Walter Fendt physlet 등 표준. 한국 *변위·속도·시간 그래프* 학습 활동 다수.
- **초등 적합성 ★★★**: 추천. *자동차 + 그래프* 친숙. 3~6학년 가능. 거리·속도·시간 단원과 연결 (5학년 산수).

### 후보 4 — 할선 → 접선 시연 🎬
- **퍼즐 정의**: 곡선 위 두 점이 점차 가까워지면 *할선이 접선으로 변함* 시각. 두 점 사이 거리 슬라이더.
- **풀이 흐름**: 두 점 표시 → 거리 슬라이더 줄임 → 할선이 접선에 수렴 → "왜 그럴까?" 발견
- **선례**: [GeoGebra Secant→Tangent](https://www.geogebra.org/m/NrwWBMUw) 가 정확히 동일. 표준 미분 도입 시각.
- **초등 적합성 ★★**: 부분 적합. *극한* 직관 부담. 6학년~중1 권장. 단순 *시연* 으로 노출이면 가능.

### 후보 5 — 극값 사냥 게임 🏔️
- **퍼즐 정의**: 무작위로 생성된 곡선의 *모든 극대·극소점* 을 클릭으로 잡는 게임.
- **풀이 흐름**: 매 라운드 새로운 곡선 → 봉우리·골짜기 클릭 → 빠르고 정확할수록 점수
- **선례**: 표준 게임 패턴. 페르마의 극값법(1636) 직관.
- **초등 적합성 ★★★**: 추천. 단순 클릭 게임, 봉우리·골짜기 시각 인식. 3~6학년 가능. *미분이 0* 이라는 조건은 노출 안 해도 됨.

### 후보 6 — 도함수 그리기 챌린지 ✏️
- **퍼즐 정의**: 함수 f 가 주어짐. 사용자가 *그 도함수 f'* 를 마우스로 그려본다. 정답 곡선과 비교 점수.
- **풀이 흐름**: f 표시 → 사용자가 도함수 그리기 → 일치도
- **선례**: [Calculus Visualizer split panel](https://mechsimulator.com/tools/calculus-visualizer/) 의 *역방향* 활동. 미국 교실 *graphical derivative* 워크시트.
- **초등 적합성 ★**: 어려움. f→f' 변환 추론 부담. 중학생 이상. 비추.

### 후보 7 — 자유낙하 vs 일정 속도 비교 🪂
- **퍼즐 정의**: 두 물체가 동시에 떨어진다. 하나는 자유낙하(중력), 하나는 등속도(낙하산). 위치·속도 그래프 비교.
- **풀이 흐름**: 시뮬 시작 → 두 물체 동시 낙하 → 그래프 비교 → "어느 쪽이 가속하는가?" 발견
- **선례**: 갈릴레이 자유낙하 lesson plan 다수. 한국 과학 교과 등장.
- **초등 적합성 ★★★**: 추천. 친숙한 물리 + 그래프 비교. 4~6학년 가능. 가속도 직관.

## 수학의 원리 탭 구현 계획

### 핵심 개념 4개

1. **평균 변화율 = 평균 빠르기**
   - 직관: "1시간에 50km 갔으면 평균 속도 50km/h"
   - 시각: 두 점을 잇는 *할선* 의 기울기

2. **순간 변화율 = 지금 이 순간**
   - 직관: "그런데 *지금 이 순간* 빠르기는?"
   - 시각: 두 점을 한없이 가까이 가져가면 *할선이 접선* 이 됨
   - 핵심 한 줄: 미분 = 곡선 한 점의 *접선의 기울기*

3. **도함수 — 모든 점의 변화율을 한 번에**
   - 직관: f의 변화율을 *함수로 표현* 한 것이 f'
   - 시각: f 위 점이 이동하면 f'(x) 곡선이 동시에 그려짐 (Calculus Visualizer 패턴)

4. **f' = 0 의 의미 (극값)**
   - 직관: 변화율이 0 = 더 이상 올라가지도 내려가지도 않는 *순간 정지*
   - 시각: 봉우리·골짜기에서 접선이 *수평*
   - 응용: 페르마의 극값법, 최대·최소 문제
