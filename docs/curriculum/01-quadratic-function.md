# 이차함수 — 큰코다친 청년 이야기

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 이차함수 — *큰코다친 청년 이야기* |
| **스토리 요약** | (※ 원문 확인 필요) 자기 한계를 모르고 무모하게 도전했다가 *극값* 을 넘어선 청년의 이야기. "어디까지가 최대인가" 를 묻는 이차함수의 핵심 질문으로 자연스럽게 이어짐. |
| **핵심 수학** | y = ax² + bx + c · 포물선 · 꼭짓점(극값) · x절편(근) · 판별식 |

## 교과 맥락

- **한국 정규 교과**: 이차함수는 **중3 함수 영역** ([나무위키 — 중학교 수학](https://namu.wiki/w/%EC%A4%91%ED%95%99%EA%B5%90%20%EC%88%98%ED%95%99))
- **초등(5~6학년)**: *비·비례·규칙성* 까지만 — 함수 식 조작은 정규 과정 밖
- **결론**: 초등 적합성은 *"식 학습은 무리, 시각·체험 학습은 가능"* — 학습 모드를 분리하는 설계가 핵심

## 학습 목표

1. 계수 a·b·c가 곡선 모양에 미치는 효과를 *조작* 으로 발견
2. *꼭짓점* 이 무엇인지 — 최대·최소 위치 — 직관적으로 체감
3. 자연·생활 속 포물선(분수, 다리, 포탄 궤적) 을 인지

## 관련 사이트 내 퍼즐

- `linear-function` — 직접 선행 (1차 → 2차 차수 한 단계 증가)
- `multiplication` — 인수분해 시각화
- `squares` — 1+3+5+...=n² 시각 증명, 이차함수의 *이산판*

## 수학퍼즐 후보 조사

### 후보 1 — 포탄 표적 맞히기 🎯
- **퍼즐 정의**: 좌측 대포 → 우측 표적. 발사각 / 초속 슬라이더로 궤적 조절. 발사 시 포물선 애니메이션. 명중하면 다음 레벨.
- **풀이 흐름**: 슬라이더 조정 → 미리보기 궤적 → 발사 → 명중/실패 → 재시도
- **선례**: GeoGebra의 *Quadratic Angry Birds* 가 사실상 동일 컨셉으로 검증된 게임. 우리 사이트 자체 구현 가치 = 책 스토리(큰코다친 청년) 와의 매칭 + 한국어 + 단원 일관성.
- **초등 적합성 ★★★**: 추천. *식을 몰라도 슬라이더만으로* 직관 학습 가능. 4~6학년 단독 풀이 가능. 식은 *현재 궤적 옆 작게* 노출 정도면 부담 적음. 책 스토리(무모한 청년) 와도 가장 잘 맞음.

### 후보 2 — 마시멜로 발사기 시뮬 🍡
- **퍼즐 정의**: 미국 교실에서 흔한 *catapult* 활동의 디지털화. 스프링·각도·물체 무게 슬라이더로 마시멜로를 발사 → 포물선 궤적 + 컵에 들어가면 점수.
- **풀이 흐름**: 변수 조절 → 발사 → 컵까지 궤적 추적 → 점수
- **선례**: [Study.com Parabola Project Ideas](https://study.com/academy/lesson/parabola-project-ideas.html) 의 "Marshmallow Catapult" 활동
- **초등 적합성 ★★★**: 추천. 후보 1과 본질 동일하나 *물리 변수 다양* 해 학습 폭 넓음. 4~6학년 모두 가능. 단점: 포탄과 컨셉 중복.

### 후보 3 — 분수 디자이너 ⛲
- **퍼즐 정의**: 분수의 물줄기 *최고점* 위치를 드래그로 조절. 그에 맞는 이차식이 자동 생성. 미션: "수반에 정확히 떨어지게".
- **풀이 흐름**: 최고점 드래그 → 수식 자동 갱신 → 떨어지는 위치 확인 → 미션 도전
- **선례**: 직접 동일 인터랙티브는 발견 못함. PhET 의 슬라이더 자유도가 가장 가까움. *생활 응용* 으로 새로운 느낌.
- **초등 적합성 ★★**: 부분 적합. 드래그 자체는 직관적이나 "수식이 왜 그렇게 변하는가" 이해엔 표준형 식 개념(중3) 필요. 5~6학년 + 보조 설명 필요. 식 표기 제거한 *모양 맞추기* 모드면 ★★★.

### 후보 4 — 다리 아치 설계 🌉
- **퍼즐 정의**: 강 양쪽 끝점이 주어지고, 다리 *최고점 높이·위치* 를 조절해 강 폭에 맞는 아치 설계. 너무 낮으면 배 못 지나가고 너무 높으면 비효율.
- **풀이 흐름**: 강 폭·배 높이 조건 확인 → 슬라이더 2개 조정 → 아치 곡선 → "통과 가능" 판정
- **선례**: 종이접기 / 동심원 작도 활동 ([Plummer EMAT 6690 Unit Plan](https://jwilson.coe.uga.edu/EMAT6680Fa10/Plummer/EMAT%206690/Unit%20Plan/Parabola_Lesson2.pdf)) 에서 도형적 접근 사례. 본 후보는 그 디지털화.
- **초등 적합성 ★★★**: 추천. 도형적 사고만으로 풀이, 수식 안 봐도 됨. 4~5학년 가능. 응용감(공학)으로 동기부여 좋음.

### 후보 5 — 그래프-식 카드 매칭 🃏
- **퍼즐 정의**: 카드 짝맞추기. 한쪽엔 그래프 4~6장, 반대쪽엔 식. 짝을 맞추면 점수.
- **풀이 흐름**: 그래프 보고 식 선택 → 즉시 정오답 → 시간 점수
- **선례**: GeoGebra *Quadratic Form Game* 와 유사 컨셉 (두 팀 형태)
- **초등 적합성 ★**: 어려움. 식을 *읽을 수 있어야* 가능 — 중학생 이상. 4~6학년에는 부담 큼. 식 대신 *말로 표현* (예: "위로 볼록, y절편 +3") 카드로 바꾸면 ★★, 그래도 추상도 높음.

### 후보 6 — 종이접기 포물선 발견 📄
- **퍼즐 정의**: 종이 한 장에 점 한 개를 찍고, 변과 그 점 사이를 접어 *접힌 자국이 만드는 곡선* 이 포물선. 디지털 시뮬레이션으로 *접는 동작* 을 슬라이더 또는 자동 애니메이션으로.
- **풀이 흐름**: 점·변 표시 → 한 변씩 점으로 접기 → 누적 접힌 선들이 포물선을 그림 → "이게 포물선!" 발견
- **선례**: [Annenberg Learner Insights into Algebra](https://www.learner.org/series/insights-into-algebra-1-teaching-for-learning-2/quadratic-functions/workshop-4-quadratic-functions-lesson-plan-1/) 등에서 paper-folding 정식 소개
- **초등 적합성 ★★★**: 추천. *순수 도형* 활동, 조작이 시각적이고 가위질·접기 친숙. 3~6학년 모두 가능. 동시에 *포물선의 정의(초점-준선)* 를 자연스럽게 도입 — 깊이도 있음.

### 후보 7 — 근(x절편) 사냥 🏹
- **퍼즐 정의**: 그래프가 등장하면 *x축과 만나는 점* 을 클릭. 빠르고 정확할수록 점수.
- **풀이 흐름**: 무작위 그래프 → x절편 클릭 → 정답이면 다음 라운드
- **선례**: 표준 게임 패턴. 직접 인터랙티브 사례는 흔하지 않으나 *Whack-a-mole* 류 게임화로 자주 보임.
- **초등 적합성 ★★★**: 추천. 단순 클릭 게임이라 3~6학년 모두 가능. *근의 개수 0/1/2* 가 자연스럽게 노출. 부담 0.

## 수학의 원리 탭 구현 계획

선정 퍼즐과 함께 *원리* 를 별도 탭으로 분리해 체계 학습.

### 핵심 개념 4개 (노출 순서)

1. **포물선이란?**
   - 직관: "공이 떨어지는 자리, 분수의 물줄기" 사진/도해
   - 정의: y = ax² 의 가장 단순한 모양 (a=1)
   - 시각: a 값을 0.5 / 1 / 2 로 바꿔보며 *얼마나 가파른가* 비교

2. **a, b, c 는 무엇을 바꾸나?**
   - a 슬라이더만: 위·아래 볼록, 좁고 넓은
   - c 슬라이더만: 위·아래 평행이동 (y절편)
   - b 슬라이더만: 좌·우 미끄러짐 (대칭축 이동)
   - 시각: 한 슬라이더만 움직이고 다른 둘 고정 (PhET 패턴)

3. **꼭짓점 — 가장 높거나 낮은 자리**
   - 직관: "포탄이 가장 높이 올라간 순간"
   - 자가 점검: 위로 볼록하면 꼭짓점은 *최고점인가 최저점인가?*
   - 시각: 마커로 꼭짓점 강조

4. **x절편(근) — 땅에 닿는 자리**
   - 직관: "포탄이 떨어지는 두 자리"
   - 0개 / 1개 / 2개 — 그림으로 분류 (판별식 도입의 직관)
   - 시각: 3가지 경우를 카드로 병치

### 시각화 자산
- `CoordPlane` 재사용 (포물선 곡선 + 꼭짓점·근 마커)
- 각 개념 카드마다 *작은 미니그래프* 한 개

### 자가 점검 질문 (탭 끝에)
1. a > 0 일 때 그래프는 위·아래 어느 쪽이 볼록한가?
2. y = x² + 4 의 꼭짓점은 (0, ?) 어디인가?
3. 그래프가 x축과 만나지 않으면 근은 몇 개인가?
