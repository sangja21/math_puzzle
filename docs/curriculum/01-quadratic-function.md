# 이차함수 — 큰코다친 청년 이야기

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 이차함수 — *큰코다친 청년 이야기* |
| **스토리 요약** | (※ 원문 확인 필요) 자신의 한계를 모르고 무모하게 도전했다가 실패한 청년의 이야기로, 이차함수의 *극값(꼭짓점)* — 즉 "어디까지가 최대인가"의 개념을 이끌어냄. |
| **핵심 수학** | y = ax² + bx + c · 포물선 · 꼭짓점 · 판별식 · 근의 공식 |
| **학습 목표** | ① 계수 a, b, c가 곡선 모양을 어떻게 바꾸는지 발견 ② 꼭짓점·근·축의 의미를 시각으로 체득 ③ 이차함수가 자연·생활 속(투사체, 분수, 아치)에 어떻게 등장하는지 인지 |

## 관련 수학퍼즐 조사

### 사이트 내 연관 퍼즐
- `linear-function` — 직접 후속. 1차→2차로 차수가 한 단계 증가하는 자연스러운 흐름. **CoordPlane 자산 재사용 가능**.
- `multiplication` — 인수분해와 약하게 연결 (이차식의 인수분해를 시각화하면 면적 모델로 환원).
- `squares` — 1+3+5+...=n² 의 시각 증명. 이차함수의 *이산판*으로 인용 가능.

### 외부 클래식 퍼즐·사례
- **갈릴레이의 낙체 실험** (1638) — 자유낙하 거리 ∝ t². 이차함수의 가장 유명한 물리 사례.
- **포탄 궤적** — 발사각·초속에 따른 사거리. 군사·체육 현장의 모든 투사체.
- **분수·다리 아치** — 시각적으로 가장 친숙한 포물선.
- **회중전등의 반사면** (포물면) — 반사형 자동차 헤드라이트, 위성 안테나.
- **케플러의 행성궤도** — 도입부 비교(타원이지만 포물선 궤적은 탈출속도 경계).

## 구현 안건

### 안건 A — 표준 하네스 (탐험기 + 퀴즈 + 코딩)
- **컨셉**: `linear-function`과 정확히 같은 3탭 구조. 일관성 최대.
- **탐험기**: a, b, c 슬라이더 → 곡선 즉시 반응. 꼭짓점·축·y절편을 마커로 표시. *대회 모드*: 무작위 목표 곡선을 슬라이더로 맞추기.
- **퀴즈**: 단계별 — (1) 위로/아래로 볼록? (2) 꼭짓점 좌표는? (3) x절편 개수는? (4) 축의 방정식은?
- **코딩 탭**: x → y 표 + 파이썬 의사코드 `def f(x): return a*x*x + b*x + c`.
- **시각화 자산**: `CoordPlane` (linear에서 추출하면 그대로 재사용).
- **예상 공수**: 소 (linear 복제 + 곡선 렌더링 추가).
- **장점**: 일관된 UX, 빠른 출시, 다음 단원의 표준 검증.
- **단점**: linear와 시각적으로 너무 유사 → "또 비슷한 페이지" 인상.

### 안건 B — 포탄 발사 시뮬레이터 (시뮬 중심)
- **컨셉**: 발사각·초속을 조절해 표적을 맞히는 게임. 상단에 *현재 궤적의 이차식 표시*.
- **메인 화면**: 좌측 대포 → 우측 표적. 슬라이더로 각도 θ, 초속 v를 조절하면 궤적이 미리 그려지고, "발사" 시 포탄이 애니메이션으로 비행.
- **수학 노출**: 궤적 옆에 실시간으로 `y = -gx²/(2v²cos²θ) + x·tanθ` 수식 → "이게 이차함수다" 발견.
- **레벨**: 표적 위치, 장애물(벽), 바람 등으로 5~8단계.
- **보조 탭**: "수학 들여다보기" — 궤적 위 점을 끌면 그 순간의 (x, y) 좌표 표시, 꼭짓점 강조.
- **예상 공수**: 중 (물리 시뮬 + 충돌 검사 + 레벨 데이터).
- **장점**: 가장 재미있고 직관적. 책의 "큰코다친 청년" = 무모한 발사로 자연 매핑.
- **단점**: 이차함수 *수식 자체*에 대한 학습 깊이는 안건 A보다 얕을 수 있음.

### 안건 C — 분수·아치 디자이너 (창작 중심)
- **컨셉**: 사용자가 포물선으로 분수·다리 아치·헤드라이트 반사면을 *디자인*.
- **모드 1 — 분수 만들기**: 물줄기 꼭짓점 위치를 드래그 → 그에 맞는 이차식이 자동 생성. "수반에 깔끔히 떨어지는" 조건 도전.
- **모드 2 — 아치 다리 설계**: 양 끝점 + 최고점 입력 → 다리 곡선 그리기. 강 폭에 맞는 다리 만들기 미션.
- **모드 3 — 반사면 실험**: 포물면에 평행 광선을 쏘면 모두 초점에 모이는 시각화 ("이게 안테나·헤드라이트의 원리").
- **예상 공수**: 중~대 (3개 모드의 그래픽).
- **장점**: 응용 사례가 풍부, 창작감, 책의 *생활 속 수학* 톤과 잘 맞음.
- **단점**: 모드 3개라 분량이 부담스럽고 한 모드에 깊이 집중 못 할 위험.

## 추천
