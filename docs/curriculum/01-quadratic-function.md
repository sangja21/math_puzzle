# 이차함수 — 큰코다친 청년 이야기

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 이차함수 — *큰코다친 청년 이야기* |
| **스토리 요약** | (※ 원문 확인 필요) 자기 한계를 모르고 무모하게 도전했다가 *극값* 을 넘어선 청년의 이야기. "어디까지가 최대인가" 를 묻는 이차함수의 핵심 질문으로 자연스럽게 이어짐. |
| **핵심 수학** | y = ax² + bx + c · 포물선 · 꼭짓점(극값) · x절편(근) · 판별식 |

## 학습 목표

1. 계수 a·b·c가 곡선 모양에 미치는 효과를 *조작* 으로 발견
2. *꼭짓점* 이 무엇인지 — 최대·최소 위치 — 직관적으로 체감
3. 자연·생활 속 포물선(분수, 다리, 포탄 궤적) 을 인지

## 관련 사이트 내 퍼즐

- `linear-function` — 직접 선행 (1차 → 2차 차수 한 단계 증가)
- `multiplication` — 인수분해 시각화
- `squares` — 1+3+5+...=n² 시각 증명, 이차함수의 *이산판*

## 수학퍼즐 후보 조사

### 후보 1 — 포탄 표적 맞히기 🎯
- **퍼즐 정의**: 좌측 대포에서 포탄 발사. 우측 표적 위치를 맞히려면 *발사각* 과 *초속* 을 슬라이더로 조절. 발사 버튼 → 포물선 궤적 애니메이션. 표적 명중 시 다음 레벨.
- **풀이 흐름**: 슬라이더 조정 → 미리보기 궤적 확인 → 발사 → 명중/실패 피드백 → 재시도
- **핵심 수학**: 포물선 궤적, 꼭짓점 = 최고점, 발사각이 거리에 미치는 영향(45° 최대)
- **초등학생 적합성 ★★★**: 추천. 식을 몰라도 슬라이더만으로 직관 학습 가능. 4~6학년 단독 풀이 가능. 식은 *현재 궤적 옆 작게* 노출 정도면 부담 적음.

### 후보 2 — 분수 디자이너 ⛲
- **퍼즐 정의**: 분수의 물줄기 *최고점* 위치를 드래그로 조절. 그에 맞는 이차식이 자동 생성되어 표시. 미션: "수반에 정확히 떨어지게 만들기".
- **풀이 흐름**: 최고점 드래그 → 수식 자동 갱신 → 떨어지는 위치 확인 → 미션 도전
- **핵심 수학**: 꼭짓점 좌표와 식의 관계 (y = a(x-h)² + k), 대칭축
- **초등학생 적합성 ★★**: 부분 적합. *드래그 자체* 는 직관적이지만 "수식이 왜 그렇게 변하는가" 를 이해하려면 표준형 식 개념 필요. 5~6학년 + 보조 설명 필요. 식 표기 없이 *모양 맞추기* 모드만 분리하면 ★★★.

### 후보 3 — 다리 아치 설계 🌉
- **퍼즐 정의**: 강 양쪽 끝점이 주어짐. 다리 *최고점 높이* 와 *위치* 를 조절해 강 폭에 맞는 아치 설계. 너무 낮으면 배가 못 지나가고, 너무 높으면 비효율.
- **풀이 흐름**: 강 폭·배 높이 조건 확인 → 슬라이더 2개 조정 → 아치 곡선 그려짐 → "통과 가능" 판정
- **핵심 수학**: 포물선 도형, 양 끝점·꼭짓점으로 곡선 결정
- **초등학생 적합성 ★★★**: 추천. 도형적 사고만으로 풀이 가능, 수식 안 봐도 됨. 4~5학년 가능. 응용감(공학) 으로 동기부여 좋음.

### 후보 4 — 그래프-식 카드 매칭 🃏
- **퍼즐 정의**: 카드 짝맞추기 게임. 한쪽엔 그래프 4~6장, 반대쪽엔 식 4~6개. 짝을 맞추면 점수.
- **풀이 흐름**: 그래프 보고 식 선택 → 즉시 정오답 → 시간 누적 점수
- **핵심 수학**: 식과 그래프의 1:1 매칭, 모양 → a 부호, y절편 → c, 꼭짓점 위치
- **초등학생 적합성 ★★**: 부분 적합. *식을 읽을 수 있어야* 가능. 6학년~중1 이상 권장. 4~5학년에는 부담. 식 대신 *말로 표현* (예: "위로 볼록, y절편 +3") 카드로 바꾸면 ★★★.

### 후보 5 — 근(x절편) 사냥 🏹
- **퍼즐 정의**: 그래프가 등장하면 *x축과 만나는 점* 을 클릭. 빠르고 정확할수록 점수.
- **풀이 흐름**: 무작위 그래프 표시 → x절편 클릭 → 정답이면 다음 라운드
- **핵심 수학**: 근 = x절편 = f(x)=0의 해. 근의 개수와 판별식 직관
- **초등학생 적합성 ★★★**: 추천. 단순 클릭 게임이라 **3~6학년 모두** 가능. *근의 개수 0/1/2* 가 자연스럽게 노출. 부담 0.

### 후보 6 — 꼭짓점 추리 🔍
- **퍼즐 정의**: 그래프 위 점 3개만 보여주고 *꼭짓점이 어디일지* 클릭으로 추측.
- **풀이 흐름**: 점 3개 등장 → 꼭짓점 위치 클릭 → 실제 곡선 + 정답 공개 → 다음
- **핵심 수학**: 대칭축, 점들의 평균을 통한 꼭짓점 추정
- **초등학생 적합성 ★**: 어려움. 추론 부담 큼, 대칭 개념 필수. 6학년~중1 정도라야 가능. 비추.

## 수학의 원리 탭 구현 계획

선정 퍼즐과 함께 *원리* 를 별도 탭으로 분리해 체계 학습.

### 핵심 개념 4개 (노출 순서)

1. **포물선이란?**
   - 직관: "공이 떨어지는 자리, 분수의 물줄기" 사진/도해
   - 정의: y = ax² 의 가장 단순한 모양 (a=1)
   - 시각: a 값을 0.5/1/2 로 바꿔보며 *얼마나 가파른가* 비교

2. **a, b, c 는 무엇을 바꾸나?**
   - a 슬라이더만: 위·아래 볼록, 좁고 넓은
   - c 슬라이더만: 그래프가 위·아래로 평행이동 (y절편)
   - b 슬라이더만: 좌·우로 미끄러짐 (대칭축 이동)
   - 시각: 한 슬라이더만 움직이고 다른 둘은 고정

3. **꼭짓점 — 가장 높거나 낮은 자리**
   - 직관: "포탄이 가장 높이 올라간 순간"
   - 자가 점검 질문: 위로 볼록하면 꼭짓점은 *최고점인가 최저점인가?*
   - 시각: 마커로 꼭짓점 강조

4. **x절편(근) — 땅에 닿는 자리**
   - 직관: "포탄이 떨어지는 두 자리"
   - 0개 / 1개 / 2개 — 그림으로 분류
   - 시각: 3가지 경우를 카드로 병치

### 시각화 자산
- `CoordPlane` 재사용, 포물선 곡선 + 꼭짓점·근 마커
- 각 개념 카드마다 *작은 미니그래프* 한 개 (전체 그래프 아님)

### 자가 점검 질문 (탭 끝에)
1. a > 0 일 때 그래프는 위·아래 어느 쪽이 볼록한가?
2. y = x² + 4 의 꼭짓점은 (0, ?) 어디인가?
3. 그래프가 x축과 만나지 않으면 근은 몇 개인가?
