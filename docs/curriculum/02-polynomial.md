# 다항함수 — 조국을 구한 아르키메데스

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 다항함수 — *조국을 구한 아르키메데스* |
| **스토리 요약** | (※ 원문 확인 필요) 시라쿠사를 침공한 로마군에 맞서 아르키메데스가 투석기·거울 등 정교한 장치로 조국을 방어한 일화. *고차의 곡선·곡면*을 정밀하게 다루는 능력을 다항함수의 도입으로 연결. |
| **핵심 수학** | y = aₙxⁿ + ... + a₀ · 차수와 곡선 모양의 관계 · 근의 개수 · 끝단 거동 · 변곡 |
| **학습 목표** | ① 차수가 곡선 모양에 미치는 효과 직관 ② 같은 점들을 지나는 다항이 *유일하게* 정해진다는 보간법 발상 ③ 차수와 근 개수의 관계 (대수학의 기본정리 도입) |

## 관련 수학퍼즐 조사

### 사이트 내 연관 퍼즐
- `linear-function`, `quadratic-function` — 차수 1, 2의 직접 선행. 본 단원에서 *차수 슬라이더*로 둘을 한 번에 다시 만남.
- `consecutive-node` — 제약 충족(CSP). 다항보간이 "주어진 점을 모두 만족" 제약과 닮음.
- `machin` — 급수 = 다항의 무한 확장 (테일러 도입의 씨앗).

### 외부 클래식 퍼즐·사례
- **아르키메데스의 투석기 / 거울** — 매끈한 곡면 = 고차 다항 근사.
- **베지에 곡선** — 디자인·폰트·애니메이션의 핵심. 3차 다항의 일상화.
- **라그랑주 보간법** — n+1개 점을 지나는 n차 다항이 유일.
- **룽게 현상** — 차수만 무작정 올리면 오히려 진동 폭발 (다항의 *역설*).
- **호너의 방법** — 다항을 효율적으로 계산하는 알고리즘.

## 구현 안건

### 안건 A — 표준 하네스 (차수 슬라이더 + 계수 슬라이더)
- **컨셉**: 차수 n을 1~5로 슬라이드, 각 차수의 계수를 작은 슬라이더로 미세 조정.
- **탐험기**: 차수 변경 시 곡선 모양·근 개수·끝단 거동(±∞에서)이 즉시 변화. 토글로 "근만 표시" / "변곡점만 표시" 모드.
- **퀴즈**: (1) 끝이 위로/아래로? (2) 근의 *최대* 개수는? (3) 주어진 그래프의 차수 추정.
- **코딩 탭**: 호너의 방법 의사코드 + 동일 결과 비교 (`((a*x+b)*x+c)*x+d`).
- **예상 공수**: 소 (linear/quadratic 자산 그대로 + 차수 가변).
- **장점**: 일관 UX, 차수 효과를 한 화면에서 비교.
- **단점**: 단원 1·2와 차이가 약해 보일 수 있음 ("그냥 슬라이더 하나 늘었네").

### 안건 B — 곡선 통과시키기 (보간 게임)
- **컨셉**: 사용자가 좌표평면에 점을 N개 찍으면, *그 점들을 모두 지나는 N-1차 다항*이 자동으로 그려짐.
- **메인 동선**: 점 추가/삭제/드래그로 곡선 형태 즉시 갱신. 차수가 *왜 N-1인지* 한 줄 안내.
- **챌린지 모드**: 미션으로 주어진 모양(예: "S자", "낙타혹 두 개")을 점 배치만으로 재현.
- **함정 모드**: 룽게 현상 — "점을 11개 찍으니 가장자리가 미친 듯 진동한다" 시연 → 차수만 올리는 게 답이 아님 학습.
- **예상 공수**: 중 (라그랑주 보간 구현 + 점 드래그 UI).
- **장점**: "다항이 점을 외운다"는 가장 핵심적인 직관을 게임화. 룽게 현상까지 자연스럽게 노출.
- **단점**: 일반 학생에게 보간법은 약간 어려운 개념 — 도입부 글이 중요.

### 안건 C — 아르키메데스 방어전 (게임화)
- **컨셉**: 시라쿠사 성벽 방어 미니게임. 적의 위치(여러 점)에 맞춰 *고차 곡선의 투석 궤적*을 만들어 한 번에 다수 격파.
- **메인 동선**: 적 좌표가 N개 찍히면, "한 번의 발사로 N개를 모두 통과"하려면 어떤 차수가 필요한가? — 차수를 정해 발사.
- **레벨 진행**: 1차→2차→3차 적 수가 늘면서 차수 학습이 자연스럽게 강요됨.
- **시각효과**: 거울로 빛 모으기(포물면), 투석기 곡선 (3차 이상) 등.
- **예상 공수**: 대 (게임 로직 + 레벨 + 그래픽).
- **장점**: 책 스토리와 직결, 가장 몰입도 높음.
- **단점**: 공수 큼. 게임성에 집중하면 수식 학습은 얕아질 수 있음.

## 추천

- **1차 추천: 안건 B (곡선 통과시키기)** — 보간법 + 룽게 현상까지 한 페이지에서 다루면 다항함수의 *깊은 직관*까지 잡음. 공수 대비 학습 효과 최고.
- **2차 추천: 안건 A** — Phase A를 빠르게 마무리하려면 표준 하네스로 진행하고, 게임화는 추후 별도 퍼즐로 분리.
