# 다항함수 — 조국을 구한 아르키메데스

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 다항함수 — *조국을 구한 아르키메데스* |
| **스토리 요약** | (※ 원문 확인 필요) 시라쿠사를 침공한 로마군에 맞서 아르키메데스가 정교한 곡선·곡면을 다루는 장치(투석기·거울)로 조국을 방어. *고차의 곡선* 을 정밀하게 다루는 능력이 다항함수와 연결. |
| **핵심 수학** | y = aₙxⁿ + ... + a₀ · 차수 ↔ 곡선 모양 · 근의 개수 · 끝단 거동 |

## 학습 목표

1. 차수가 곡선의 *굽이 수* 를 결정한다는 직관
2. 같은 점들을 지나는 *유일* 다항이 존재한다는 보간 발상
3. 차수만 무작정 올리면 *역설* 적으로 곡선이 미쳐 날뛴다 (룽게)

## 관련 사이트 내 퍼즐

- `linear-function`, (이차함수) — 차수 1, 2의 직접 선행
- `consecutive-node` — 제약 충족(CSP), "주어진 점 모두 만족" 사고와 닮음
- `machin` — 급수 = 다항의 무한 확장 (도입 한 줄)

## 수학퍼즐 후보 조사

### 후보 1 — 점 통과 곡선 만들기 ✏️
- **퍼즐 정의**: 좌표평면에 점을 N개 찍으면, *그 점들을 모두 지나는 다항* 이 자동으로 그려짐. 점을 추가/이동/삭제하며 곡선 모양 변화 관찰.
- **풀이 흐름**: 점 클릭 추가 → 곡선 자동 갱신 → 미션(예: "S자 모양 만들기")
- **핵심 수학**: 라그랑주 보간, N개 점 → N-1차
- **초등학생 적합성 ★★**: 일부 적합. 점 찍기·드래그는 직관적이지만 "왜 차수가 이렇게 정해지나" 는 어려움. 5~6학년 가능, *차수 표시 끄기* 모드면 ★★★.

### 후보 2 — 차수 추리 게임 🎲
- **퍼즐 정의**: 다항 그래프가 등장. 사용자는 *몇 차 함수일지* 답함. 굽이 수와 끝단 거동으로 추정.
- **풀이 흐름**: 그래프 표시 → 1·2·3·4·5차 중 선택 → 정오답 + 해설
- **핵심 수학**: 차수 N → 굽이 N-1개, 양 끝 ±∞에서의 거동
- **초등학생 적합성 ★★**: 부분 적합. 굽이 *세기* 자체는 4~5학년도 가능하지만 "차수" 라는 용어가 낯설 수 있음. *굽이 수* 로 묻는 변형이면 ★★★.

### 후보 3 — 룽게 함정 시연 ⚠️
- **퍼즐 정의**: 점을 5개·9개·13개 늘려가며 *고차 다항* 이 가장자리에서 *진동 폭발* 하는 모습을 관찰.
- **풀이 흐름**: 점 개수 슬라이더 → 곡선 변화 관찰 → "진동이 가장 적은 점 개수는?" 퀴즈
- **핵심 수학**: 룽게 현상, 차수만 올리면 안 된다는 *반례*
- **초등학생 적합성 ★**: 어려움. 시연 가치는 있지만 *왜* 그렇게 되는지 설명이 추상적. 중학생 이상 권장. 단원의 *마지막 한 컷* 으로만 노출이면 OK.

### 후보 4 — 곡선 따라 그리기 ✍️
- **퍼즐 정의**: 화면에 다항 곡선이 흐릿하게 보임. 사용자가 마우스로 곡선을 *따라 그리면* 정확도 점수.
- **풀이 흐름**: 곡선 표시 → 마우스 드래그로 따라가기 → 일치도 % 표시
- **핵심 수학**: 다항의 모양 인식, 시각·운동 협응
- **초등학생 적합성 ★★★**: 추천. 수학 부담 0, 그리기 자체가 즐거움. 3~6학년 모두 가능. *모양 외우기* 차원에서 효과적.

### 후보 5 — 투석기 표적 (곡선 발사) 🏰
- **퍼즐 정의**: 아르키메데스의 투석기. 적이 N개 점에 흩어져 있고, *N-1차 곡선* 으로 모두를 통과하는 발사 궤적 설계. 차수가 부족하면 모두 못 맞힘.
- **풀이 흐름**: 적 위치 표시 → 차수 선택 → 발사 곡선 그려짐 → 명중 수 카운트
- **핵심 수학**: N개 점 통과 → N-1차 필요, 보간법의 게임화
- **초등학생 적합성 ★★**: 부분 적합. 게임성 좋으나 *차수가 부족하면 왜 안 되는지* 추론 필요. 5~6학년 + 도움말 필요.

### 후보 6 — 끝단 거동 매칭 ↗️↘️
- **퍼즐 정의**: 그래프 4장 + "양쪽 위로 / 양쪽 아래로 / 한쪽 위 한쪽 아래" 같은 카드. 짝맞추기.
- **풀이 흐름**: 카드 보고 그래프 선택 → 정오답
- **핵심 수학**: 최고차항 부호와 차수의 홀짝
- **초등학생 적합성 ★★**: 부분 적합. 그래프 *모양 분류* 는 가능, 용어("최고차항") 는 부담. 5~6학년 적당.

## 수학의 원리 탭 구현 계획

### 핵심 개념 4개

1. **차수 = 굽이 수**
   - 직관: 1차 = 직선(굽이 0), 2차 = 한 굽이, 3차 = 두 굽이…
   - 시각: 차수 슬라이더(1~5) 한 번만 움직이며 굽이 수 카운트

2. **같은 점들을 지나는 곡선이 *딱 하나* 있다**
   - 직관: 점 2개 → 직선 1개 (1차), 점 3개 → 포물선 1개 (2차)
   - 일반화: 점 N개 → N-1차 곡선이 *유일*
   - 시각: 점 3개를 사용자가 드래그, 곡선이 자동 따라옴

3. **양쪽 끝은 어떻게 되는가**
   - 짝수 차수: 양쪽 같은 방향
   - 홀수 차수: 양쪽 반대
   - 시각: 차수별 카드 4장 (2,3,4,5차)

4. **차수만 올리면 위험하다 (룽게)**
   - 13차 다항이 가장자리에서 *날뛰는* 그림
   - 메시지: 정확도와 차수는 같지 않다

### 시각화 자산
- `CoordPlane` 재사용
- 차수별 미리 계산된 곡선 샘플 (라이브러리에서)
- 점 드래그 컴포넌트 신규 (단원 전용)
