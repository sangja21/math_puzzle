# 다항함수 — 조국을 구한 아르키메데스

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 다항함수 — *조국을 구한 아르키메데스* |
| **스토리 요약** | (※ 원문 확인 필요) 시라쿠사를 침공한 로마군에 맞서 아르키메데스가 정교한 곡선·곡면을 다루는 장치(투석기·거울)로 조국을 방어. *고차의 곡선* 을 정밀하게 다루는 능력이 다항함수와 연결. |
| **핵심 수학** | y = aₙxⁿ + ... + a₀ · 차수 ↔ 곡선 모양 · 근의 개수 · 끝단 거동 |

## 교과 맥락

- **한국 정규 교과**: 다항함수 *식 자체* 는 고등학교 (수학Ⅰ·Ⅱ 또는 미적분) 에서 본격 학습 ([나무위키 — 다항함수](https://namu.wiki/w/%EB%8B%A4%ED%95%AD%ED%95%A8%EC%88%98))
- **중학교**: 일차·이차까지만
- **초등(5~6학년)**: 다항식 자체는 정규 외. 그러나 *곡선 디자인·점 통과 추론* 같은 시각 과제는 가능
- **결론**: 식 학습은 어려움. *Bezier 게임* 류의 곡선 조작·조형 활동으로 풀어내면 초등도 접근 가능

## 학습 목표

1. 차수가 곡선의 *굽이 수* 를 결정한다는 직관
2. 같은 점들을 지나는 *유일* 다항이 존재한다는 보간 발상
3. 차수만 무작정 올리면 곡선이 미쳐 날뛴다 (룽게 — 도입만)

## 관련 사이트 내 퍼즐

- `linear-function`, (이차함수) — 차수 1, 2의 직접 선행
- `consecutive-node` — 제약 충족(CSP), "주어진 점 모두 만족" 사고와 닮음
- `machin` — 급수 = 다항의 무한 확장 (도입 한 줄)

## 수학퍼즐 후보 조사

### 후보 1 — 점 통과 곡선 만들기 (보간 게임) ✏️
- **퍼즐 정의**: 좌표평면에 점 N개를 클릭으로 추가하면 *그 점들을 모두 지나는 다항* 이 자동으로 그려짐. 점을 추가/이동/삭제하며 곡선 변화 관찰.
- **풀이 흐름**: 점 클릭 추가 → 곡선 자동 갱신 → 미션(예: "S자 모양 만들기") 도전
- **선례**: [Polynomial Interpolation Tool (timodenk)](https://tools.timodenk.com/polynomial-interpolation) 가 사실상 동일 기능. [dCode](https://www.dcode.fr/lagrange-interpolating-polynomial) 는 *식까지* 보여줌. 우리 사이트의 가치 = 게임화·미션·한국어
- **초등 적합성 ★★**: 일부 적합. 점 찍기·드래그는 직관적이나 "왜 차수가 이렇게 정해지나" 는 어려움. 5~6학년 가능. **차수 표시 OFF / 모양 ON** 모드로 분리하면 ★★★.

### 후보 2 — Bezier 디자인 챌린지 🎨
- **퍼즐 정의**: 시작·끝점이 주어진 곡선의 *제어점* 두 개를 드래그해 미션 모양(자동차 곡선, 글자 획, 다리 곡선) 만들기.
- **풀이 흐름**: 미션 모양 회색으로 표시 → 제어점 드래그로 일치도 ↑ → 점수
- **선례**: [The Bézier Game](https://bezier.method.ac/) 가 정확히 이 게임. 디자인 학습용으로 매우 유명. *"3차 베지에 = 3차 다항"* 으로 다항함수와 자연스럽게 연결.
- **초등 적합성 ★★★**: 추천. 식 0, 순수 시각 조작. [Bezier Art Game](https://artsology.com/bezier-art-game.php) 같은 어린이 친화 형태가 이미 존재. 4~6학년 모두 가능. *디자인의 즐거움* + 다항 직관 동시.

### 후보 3 — 차수 추리 게임 🎲
- **퍼즐 정의**: 다항 그래프 등장 → *몇 차 함수일지* 답함. 굽이 수와 끝단 거동으로 추정.
- **풀이 흐름**: 그래프 표시 → 1·2·3·4·5차 중 선택 → 정오답 + 해설
- **선례**: 직접 동일 게임은 없음. *그래프 인식* 류는 대부분 식 매칭(중학생용)에 머무름.
- **초등 적합성 ★★**: 부분 적합. *굽이 세기* 자체는 4~5학년도 가능하지만 "차수" 라는 용어가 낯섦. **"굽이 수 맞히기"** 로 리프레임하면 ★★★.

### 후보 4 — 룽게 함정 시연 ⚠️
- **퍼즐 정의**: 점을 5개·9개·13개 늘려가며 *고차 다항* 이 가장자리에서 *진동 폭발* 하는 모습 관찰.
- **풀이 흐름**: 점 개수 슬라이더 → 곡선 변화 → "진동이 가장 적은 점 개수는?" 퀴즈
- **선례**: 룽게 현상은 학술 자료에서만 다룸 — 게임화 사례 부재. 신선함 ↑.
- **초등 적합성 ★**: 어려움. 시연 가치는 있지만 *왜* 그렇게 되는지 설명이 추상. 중학생 이상 권장. 단원의 *마지막 한 컷* 으로 노출이면 OK.

### 후보 5 — 곡선 따라 그리기 ✍️
- **퍼즐 정의**: 화면에 다항 곡선이 흐릿하게 보임. 마우스로 *따라 그리면* 정확도 점수.
- **풀이 흐름**: 곡선 표시 → 마우스 드래그로 추적 → 일치도 % 표시
- **선례**: 일반적 그림 게임 패턴. 수학 학습 사례는 드물지만 *모양 외우기* 효과 있음.
- **초등 적합성 ★★★**: 추천. 수학 부담 0, 그리기 자체가 즐거움. 3~6학년 모두 가능. *모양 외우기* 차원.

### 후보 6 — 아르키메데스 방어전 🏰
- **퍼즐 정의**: 시라쿠사 성벽 방어 게임. 적이 N개 위치에 흩어져 있고, *N-1차 곡선* 발사로 모두 통과. 차수가 부족하면 못 맞힘.
- **풀이 흐름**: 적 위치 표시 → 차수 선택 → 발사 곡선 그려짐 → 명중 수 카운트
- **선례**: 직접 동일 게임 없음. 책 스토리(아르키메데스) 와 가장 잘 매칭.
- **초등 적합성 ★★**: 부분 적합. 게임성은 좋으나 *차수가 부족하면 왜 안 되는지* 추론 필요. 5~6학년 + 도움말. 차수 대신 *"점 N개를 동시에 통과하려면 곡선이 최소 N-1번 굽어야"* 라는 굽이 직관으로 풀어내면 ★★★.

### 후보 7 — 끝단 거동 매칭 ↗️↘️
- **퍼즐 정의**: 그래프 4장 + "양쪽 위로 / 양쪽 아래로 / 한쪽 위 한쪽 아래" 카드. 짝맞추기.
- **풀이 흐름**: 카드 보고 그래프 선택 → 정오답
- **선례**: 일반 매칭 게임 형태. 다항 끝단 거동은 미국 교과 표준.
- **초등 적합성 ★★**: 부분 적합. 그래프 *모양 분류* 는 가능, 용어("최고차항")는 부담. 5~6학년 적당. 용어 빼고 *"화살표 방향만"* 으로 하면 ★★★.

## 수학의 원리 탭 구현 계획

### 핵심 개념 4개

1. **차수 = 굽이 수**
   - 직관: 1차 = 직선(굽이 0), 2차 = 한 굽이, 3차 = 두 굽이…
   - 시각: 차수 슬라이더(1~5) 한 번만 움직이며 굽이 수 카운트

2. **같은 점들을 지나는 곡선이 *딱 하나* 있다 (보간)**
   - 직관: 점 2개 → 직선 1개 (1차), 점 3개 → 포물선 1개 (2차)
   - 일반화: 점 N개 → N-1차 곡선이 *유일*
   - 시각: 점 3~5개를 사용자가 드래그, 곡선이 자동 따라옴

3. **양쪽 끝은 어떻게 되는가**
   - 짝수 차수: 양쪽 같은 방향
   - 홀수 차수: 양쪽 반대
   - 시각: 차수별 카드 4장 (2,3,4,5차)

4. **차수만 올리면 위험하다 (룽게)**
   - 13차 다항이 가장자리에서 *날뛰는* 그림 한 컷
   - 메시지: 정확도와 차수는 같지 않다 — 깊이는 단원 외 (도입만)

### 시각화 자산
- `CoordPlane` 재사용
- 차수별 미리 계산된 곡선 샘플 (라이브러리에서)
- 점 드래그 컴포넌트 신규 (Bezier 방식 + Lagrange 보간 양립 가능)
