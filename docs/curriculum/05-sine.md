# 사인함수 — 피라미드의 높이는?

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 사인함수 — *피라미드들의 높이는?* |
| **스토리 요약** | (※ 원문 확인 필요) 거대한 피라미드의 높이를 직접 잴 수 없을 때, *각도와 한 변* 만 알면 알 수 있다는 측량술의 도입. (탈레스 일화는 단원 7 탄젠트로 분리됨.) |
| **핵심 수학** | sin θ = 대변/빗변 · 단위원 위의 회전 · 사인 파동 (주기·진폭·위상) · 라디안 |
| **학습 목표** | ① 직각삼각형의 비 → 사인의 정의 ② 단위원 회전이 사인 파동을 만든다는 *변환 직관* ③ 자연·생활 속 진동(파도, 음, 진자)이 사인으로 모델됨 인지 |

## 관련 수학퍼즐 조사

### 사이트 내 연관 퍼즐
- `hourglass` — 모래시계 = 주기. 사인의 *주기성* 과 약한 연관.
- `magic-square` — 무관 (참고용).
- `linear-function` — *기울기* 와 각도의 관계로 살짝 연결 (tan으로 더 강함).

### 외부 클래식 퍼즐·사례
- **단위원** — 사인·코사인을 한 화면에 통합하는 가장 강력한 도구.
- **음파·악기 화성** — 진동수 비율 (옥타브 = 2:1, 5도 = 3:2). *사인 파동의 합성*.
- **진자운동** — sin θ ≈ θ 근사로 단순조화운동.
- **파도·해일·조류**.
- **라이트하우스 / 회전등대** — 회전 → 직선상 점의 위치가 사인.
- **푸리에 분해** — 모든 주기 신호는 사인의 합 (도입 한 줄).

## 구현 안건

### 안건 A — 표준 하네스 (단위원 + 파동 동시 표시)
- **컨셉**: 좌측에 단위원 위 회전점, 우측에 그 *y좌표* 가 시간에 따라 그리는 사인 곡선. 두 화면이 한 동작으로 연동.
- **탐험기**: 각도 θ 슬라이더 또는 자동 회전. 진폭 A, 각진동수 ω, 위상 φ 슬라이더로 *A·sin(ωt + φ)* 변화.
- **퀴즈**: (1) sin 30° = ? (2) 진폭 2배 시 그래프? (3) 위상 π/2 이동 시 어떤 함수? (=cos!)
- **코딩 탭**: 각도→사인 표 + 의사코드 `import math; math.sin(math.radians(deg))`.
- **예상 공수**: 중 (단위원·파동 연동 애니메이션).
- **장점**: 사인의 *모든 핵심* 을 한 화면에. 코사인·탄젠트 페이지에서 자산 그대로 재사용.
- **단점**: 정보 밀도 높아 초보자에게 부담스러울 수 있음 (단계적 노출 필요).

### 안건 B — 측량사 미션 (피라미드 높이)
- **컨셉**: 사용자가 측량사. 피라미드(또는 빌딩, 산) 앞 일정 거리에서 *꼭대기를 올려다보는 각도* 와 *눈높이~밑면 거리* 를 입력 → 높이 계산.
- **메인 동선**: 도구 = 각도기 + 줄자 미니 게임. 측정값 입력 → "h = d·tan θ" 자동 표시 (※ 사인보다 탄젠트가 정확하지만, 사인 단원에선 *빗변을 안다고 가정* 한 변형).
- **레벨**: 피라미드 → 빌딩 → 멀리 있는 산 → 바다 위 등대.
- **사인 특화 변형**: 빗변(시선 거리)을 측정한 뒤 *sin θ × 빗변* 으로 높이.
- **예상 공수**: 중 (각도기·줄자 UI + 풍경 일러스트).
- **장점**: 책 스토리 매칭, 응용감 강함.
- **단점**: 탄젠트 단원과 메커니즘이 겹쳐 *역할 분담* 이 모호. 사인을 일부러 부각하려면 빗변 측정 트릭이 어색.

### 안건 C — 음파·화성 시각화 (사인의 합)
- **컨셉**: 사인 1개 → 사인 2개 합 → 사인 N개 합 = 임의 파형. 진폭·진동수·위상 슬라이더로 화음 만들기.
- **메인 동선**: 단일 사인을 듣고 본다 → 두 개를 합쳐 *맥놀이(beat)* 발견 → 옥타브·5도·3도의 정수비 발견.
- **사이드 모듈**: Web Audio API로 실제 *소리* 까지 재생 (옵션).
- **푸리에 미리보기**: 사각파를 사인 N개로 근사하는 시연 (N 슬라이더).
- **예상 공수**: 중~대 (Web Audio + 파동 합성).
- **장점**: 사인의 *깊이* (합성·분해)까지 도달. 가장 흥미로움.
- **단점**: 책 스토리(피라미드 측량)와 거리. 단원 6·7로의 연결도 약함.

## 추천

- **1차 추천: 안건 A (단위원 + 파동)** — 단위원 컴포넌트는 단원 6(코사인)·7(탄젠트)에서 그대로 재사용. Phase B의 *기반 자산* 으로서 가치 최고.
- **확장**: 안건 A 메인 + *"음파 실험실"* 이라는 별도 보너스 페이지로 안건 C 분리 출시 가능.
