# 사인함수 — 피라미드의 높이는?

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 사인함수 — *피라미드들의 높이는?* |
| **스토리 요약** | (※ 원문 확인 필요) 거대한 피라미드의 높이를 직접 잴 수 없을 때, *각도와 한 변* 만 알면 알 수 있다는 측량술의 도입. (탈레스 일화는 단원 7 탄젠트로 분리됨.) |
| **핵심 수학** | sin θ = 대변/빗변 · 단위원 위의 회전 · 사인 파동 (주기·진폭·위상) · 라디안 |

## 교과 맥락

- **한국 정규 교과**: 삼각비는 **중3**, 삼각함수(파동 형태)는 **고1~고2** ([나무위키 — 삼각함수](https://namu.wiki/w/%EC%82%BC%EA%B0%81%ED%95%A8%EC%88%98))
- **초등·중1·2**: *직각삼각형의 변 비율* 직관 정도까지만 가능 (*닮음* 학습)
- **결론**: 단위원·라디안은 어려움. *직각삼각형의 빗변과 대변 비율* 까지가 초등 한계. 음파·진동 *시각·청각* 체험은 어떤 학년이든 가능.

## 학습 목표

1. 직각삼각형의 *대변/빗변 비율* 이 각도에 따라 정해진다 — 사인의 정의
2. 단위원 회전이 사인 파동을 만든다는 *변환 직관* (보너스)
3. 자연·생활 속 진동(파도, 음, 진자) 이 사인으로 모델됨

## 관련 사이트 내 퍼즐

- `hourglass` — 모래시계 = 주기. 사인의 *주기성* 과 약한 연관
- `linear-function` — *기울기* 와 각도의 관계 (탄젠트로 더 강함)

## 수학퍼즐 후보 조사

### 후보 1 — 단위원 + 파동 시뮬 (PhET Trig Tour 류) ⭕📈
- **퍼즐 정의**: 좌측 단위원 위 회전점, 우측 그 *y좌표* 가 시간에 따라 그리는 사인 곡선. θ 슬라이더 또는 자동 회전.
- **풀이 흐름**: 슬라이더 회전 → 두 화면 동기 변화 → "단위원의 어디가 사인 최댓값?" 발견
- **선례**: PhET Trig Tour, GeoGebra, MathsIsFun, MiniWebTool 등 표준 자산 다수.
- **초등 적합성 ★★**: 부분 적합. *움직임 자체* 는 직관적이나 "단위원 - 사인" 연결 추론은 중학생 이상. 6학년 + 도움말이면 모양 학습 가능.

### 후보 2 — 측량사 미션 (높이 추정) 🔭
- **퍼즐 정의**: 측량사. 피라미드(또는 빌딩, 산) 앞 일정 거리에서 *꼭대기를 올려다보는 각도* 와 *눈높이~밑면 거리* 를 입력 → 높이 계산.
- **풀이 흐름**: 도구 = 각도기 + 줄자 미니 게임. 측정값 입력 → "h = d·tan θ" 자동 표시
- **선례**: 미국·영국 *trigonometry shadow lesson* 다수 ([Think Academy 탈레스](https://www.thethinkacademy.com/blog/edubriefs-thales-and-the-pyramid-measuring-height-with-shadows/), [Coach Phillips Shadow Math](https://coachchadphillips.weebly.com/uploads/1/2/0/8/120840490/unit_4_day_5_notes_-_shadow_math.pdf))
- **초등 적합성 ★★**: 부분 적합. 사인보다 탄젠트가 정확하므로 *단원 7과 역할 중복*. 사인용으로 정렬하려면 *빗변 측정* 변형이 필요한데 초등에 부담. 5~6학년 가능, 단원 7로 옮기는 편이 적절.

### 후보 3 — 단위원 트레이스 게임 ✏️
- **퍼즐 정의**: 단위원에서 점을 천천히 회전시키며 동시에 *그 점의 y좌표를 종이에 그려보기*. 자동 트레이스 모드 + 사용자 *수동 따라 그리기* 모드.
- **풀이 흐름**: 시작 → 점 회전 → 곡선 자동 그려짐 → 사용자가 따라 그리기 → 일치도
- **선례**: GeoGebra Graphing Sine 의 *trace* 기능. 학습용 변형.
- **초등 적합성 ★★★**: 추천. *그리기 게임* 으로 즐거움 + 사인 모양 외우기. 4~6학년 가능. 식 불필요.

### 후보 4 — 사인 파동 매칭 🌊
- **퍼즐 정의**: 진폭 / 진동수 / 위상 슬라이더로 사인 파동을 조절해 *목표 파동* 과 일치 시키기.
- **풀이 흐름**: 목표 파동 회색으로 표시 → 슬라이더 3개 조절 → 일치도
- **선례**: 기본 *trigonometric transformations* 활동. PhET Trig Tour 도 슬라이더 변형 가능.
- **초등 적합성 ★**: 어려움. *진폭·진동수·위상* 추상 개념. 중학생 이상. 비추.

### 후보 5 — 음파·화성 시각·청각 체험 🎵
- **퍼즐 정의**: 사인 1개 → 사인 2개 합 → 사인 N개 합 = 임의 파형. 진폭·진동수 슬라이더로 화음 만들기. 실제 *소리 재생* 동반.
- **풀이 흐름**: 단일 사인 듣기 → 두 개 합쳐 *맥놀이(beat)* 발견 → 옥타브·5도 정수비 발견
- **선례**: [Chrome Music Lab Sound Waves](https://musiclab.chromeexperiments.com/Sound-Waves) — 어린이 친화 검증 + Web Audio API. Wolfram Demonstrations 다수.
- **초등 적합성 ★★★**: 추천. *소리 + 그림* 동시이라 인지 부담 적음. 3~6학년 가능. Chrome Music Lab 의 PK-12 검증 사례.

### 후보 6 — 진자 운동 시뮬 🕰️
- **퍼즐 정의**: 진자가 좌우로 흔들림. 시간에 따른 *위치 그래프* 가 사인 곡선임을 시각.
- **풀이 흐름**: 진자 시작 → 시간 진행 + 그래프 자동 그려짐 → "이 곡선이 무엇처럼 보이는가?" 답하기
- **선례**: 물리 교과 *simple harmonic motion* lesson 다수.
- **초등 적합성 ★★★**: 추천. 진자는 친숙, 시각만으로 충분. 3~6학년 가능. 사인이 *어디서 나오는가* 자연스럽게 도입.

### 후보 7 — 사인 그래프 카드 매칭 🃏
- **퍼즐 정의**: 사인 그래프 카드 4~6장 (진폭·진동수 다름) + 식 카드. 짝맞추기.
- **풀이 흐름**: 그래프 보고 식 선택 → 정오답
- **선례**: 표준 trig matching 활동.
- **초등 적합성 ★**: 어려움. 식을 *읽을 수 있어야* 함. 중학생 이상. *말 카드* 로 변형하면 ★★, 그래도 추상도 높음.

## 수학의 원리 탭 구현 계획

### 핵심 개념 4개

1. **사인은 *비율***
   - 직관: "직각삼각형에서 *맞은편 변* 길이를 *빗변* 으로 나눈 값"
   - 시각: 직각삼각형 그림 + 한 변 강조
   - 같은 각이면 삼각형 크기와 무관하게 비율 같음 (닮음)

2. **각도가 바뀌면 비율도 바뀐다**
   - 시각: 각도 슬라이더(0°~90°) + 비율 변화 표시
   - 0°일 때 0, 90°일 때 1
   - 자가 점검: 30°·45°·60° 의 사인값?

3. **단위원이라는 마법 (보너스)**
   - 단위원 위 회전점의 y좌표가 사인
   - 90°를 넘어가면? — 사인이 음수로 떨어짐
   - 시각: 단위원 + 사인 그래프 동기 (PhET 패턴)

4. **자연 속의 사인**
   - 음파, 파도, 진자, 빛의 진동
   - 사진 4장 카드 + 한 컷씩 사인 곡선 오버레이

### 시각화 자산
- `CoordPlane` 재사용
- **신규**: `UnitCircle` 컴포넌트 — 회전점·반지름·각도 호 (단원 6·7 재사용)
- **선택**: Web Audio API (후보 5 음파 재생)

### 자가 점검 질문
1. sin 90° = ? (= 1)
2. 직각삼각형에서 빗변이 10, 대변이 5일 때 sin θ = ? (= 0.5)
3. 사인이 0이 되는 각도는? (= 0°, 180°, 360°)
