# 책 본문 인용 톤 가이드

함수~적분 9단원 구현 시 책 *『재미있는 〈수학〉 이야기』* 의 챕터 스토리를
페이지에 노출할 때의 표준. 저작권 회피와 학습 효과를 동시에 잡는 것이 목표.

## 핵심 원칙

| # | 원칙 | 근거 |
|---|------|------|
| 1 | **직접 발췌 금지** — 책 본문을 그대로 따오지 않음 | 저작권 / 표절 회피 |
| 2 | **각색·요약** — 같은 *비유와 인물* 은 사용하되 문장은 새로 씀 | 인물·소재는 일반적 사실, 표현은 재창작 |
| 3 | **3~5문장** — 한 단락, 학습 동기 환기에 충분한 분량 | 인트로 카드의 시각적 부하 제어 |
| 4 | **출처 표기** — "책 『재미있는 수학 이야기』의 〈XX〉 챕터에서 영감" 형태로 1회 표기 | 정직성 + 독자가 원작을 찾아갈 수 있도록 |
| 5 | **수학 개념 즉시 연결** — 스토리 끝에 *"여기서 등장하는 수학은 …"* 한 줄로 다리 놓기 | 스토리가 데코가 아니라 학습 도입이 되도록 |

## 형식 (`StoryHeader` 컴포넌트의 `story` slot)

```
{인물·상황 1~2문장 — 누가 무엇을 했는가}.
{핵심 사건 1~2문장 — 왜 그것이 흥미로운가, 어떤 *수학적 질문* 이 떠오르는가}.
{수학 다리 1문장 — 이 이야기의 핵심을 풀려면 ○○○ 함수/개념이 필요하다}.
```

## 좋은 예 — 일차함수 (가공 예시)

> 토끼와 거북이가 결승선을 향해 달렸다. 토끼는 처음엔 빨랐지만 중간에
> 멈췄고, 거북이는 한결같은 속도로 한 걸음씩 내디뎠다. 두 캐릭터가
> *언제* 만나고, *어떤 거북이* 가 어떤 토끼를 이길 수 있는지는 결국
> 시간에 따른 거리 변화를 따져보는 문제 — 즉 **일차함수**의 이야기다.

- 인물·소재(우화)는 보존, 표현은 새로 씀.
- "결승선/한걸음/한결같은 속도" 같은 *학습 다리* 어휘 풍부.
- 마지막 한 줄에서 *수학 개념* 명시.

## 나쁜 예 (피해야 할 패턴)

❌ "책에 따르면 토끼는 ~라고 했다" 식의 직접 인용 — 저작권 위험 + 학습 흐름 끊김
❌ 책 챕터를 *그대로 옮기는* 긴 단락 — 인트로의 부담 과다
❌ 스토리만 있고 수학 다리가 없는 경우 — 데코로 전락
❌ 인물·소재까지 새로 만든 경우 — 책과의 연결성 상실

## 체크리스트 (단원 페이지 작성 시)

각 단원의 `StoryHeader` 콘텐츠를 작성한 뒤 아래를 자가 점검:

- [ ] 본문 직접 발췌가 없는가? (한두 단어 일치는 OK, 한 문장 이상 일치는 NG)
- [ ] 분량이 3~5문장 사이인가?
- [ ] 인물·소재가 책 챕터와 동일한가? (보존되어야 함)
- [ ] 마지막에 수학 개념을 명시했는가?
- [ ] 출처 표기 또는 사이트 푸터·About 페이지에서 책 출처를 한 번이라도 밝혔는가?

## 출처 표기 위치

- **각 단원 페이지** — 별도 표기 *불필요* (사이트 단위로 한 번만 밝히면 충분).
- **사이트 About 또는 푸터** — "함수~적분 단원의 스토리는 『재미있는
  〈수학〉 이야기』(저자/출판사) 의 챕터 구성에서 영감을 받았습니다." 한 줄 표기.
  *(About 페이지가 없으면 사이드바 하단·메인 페이지 푸터 등에 추가)*

## 운영 메모

- 본 가이드를 따르더라도 *대량 동일 인물·소재 사용* 이 누적되면 출판사
  관점에서 문제될 수 있음 — 9개 단원 모두를 책의 챕터 구성과 *동일 순서*
  로 배치하기보다는, 사이트 자체 큐레이션을 일부 가미해 독립성 확보.
- 의심스러우면 해당 단원에서 *대안 일화* (외부 클래식 사례) 로 교체:
  각 기획문서의 *외부 클래식* 섹션에 이미 후보가 정리되어 있음.
