# 탄젠트함수 — 탈레스와 피라미드의 비밀

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 탄젠트함수 — *탈레스와 피라미드의 비밀* |
| **스토리 요약** | (※ 원문 확인 필요) BC 6세기, 탈레스가 *그림자의 비례* 만으로 이집트 피라미드의 높이를 알아낸 일화. 자기 키와 그림자 길이의 비 = 피라미드 높이와 그림자 길이의 비. 닮음과 탄젠트의 만남. |
| **핵심 수학** | tan θ = 대변/인접변 = sin θ / cos θ · 점근선(±π/2) · 닮음의 비례 · 경사도(%) |
| **학습 목표** | ① 탄젠트 = 사인/코사인의 비 ② *닮은 직각삼각형* 은 같은 탄젠트값 → 탈레스의 측량 ③ 일상의 경사·기울기·시야각이 탄젠트 |

## 관련 수학퍼즐 조사

### 사이트 내 연관 퍼즐
- `sine`, `cosine` (단원 5·6) — 단위원 자산 재사용. 두 함수의 *비*.
- `linear-function` — *기울기 = tan(직선의 기울기각)*. 본 단원에서 다시 한 번 의미 부여.
- `squares` — 닮음의 기하적 직관 보조.

### 외부 클래식 퍼즐·사례
- **탈레스의 피라미드 측량** — 책 챕터.
- **그림자 시계(해시계)** — 시간에 따른 그림자 길이 = 탄젠트 변화.
- **도로 경사도(%)** — 8% 경사 = tan ≈ 0.08 (4.6°).
- **카메라/눈의 시야각(FOV)** — 화면 폭 / 거리 = tan(반시야각).
- **빌딩 높이 측정 앱** — 스마트폰의 흔한 활용.
- **점근선의 직관** — 90°에 가까울수록 무한대로 — *수학에서 무한대* 의 첫 만남 중 하나.

## 구현 안건

### 안건 A — 표준 하네스 (탄젠트 그래프 + 점근선)
- **컨셉**: 단위원과 함께 탄젠트 그래프 표시. *점근선* 의 의미를 단위원에서 직접 시각 (cos θ → 0이면 tan → ∞).
- **탐험기**: θ 슬라이더로 회전, 단위원의 *직각변 비* 와 탄젠트 그래프 동시 변화. 점근선 근처에서 *왜* 발산하는지 한 줄 설명.
- **퀴즈**: (1) tan 45° = ? (2) 점근선은 어디? (3) sin/cos 와 일치하는가?
- **코딩 탭**: 닮음비 계산.
- **예상 공수**: 소 (사인·코사인 자산 재사용).
- **장점**: 단원 5·6과 트리오 완성, 점근선의 직관 효과적.
- **단점**: 책 스토리(탈레스)와 약한 연결.

### 안건 B — 탈레스 측량가 (그림자로 높이 재기)
- **컨셉**: 사용자 = 탈레스. 자기 키와 그림자 + 피라미드 그림자 → 피라미드 높이 추정.
- **메인 동선**: 풍경 일러스트 + 두 그림자 길이 슬라이더. 자동으로 *닮음 비례식* 표시 → 피라미드 높이 자동 계산.
- **레벨**: 피라미드 → 빌딩 → 큰 나무 → 멀리 있는 산. 시간에 따라 *해의 각도* 변동(그림자 길이가 자동 변경)으로 동일 물체의 그림자가 매번 달라지는 시연.
- **사이드 위젯**: 단위원 미니패널 — *지금 사용한 각도가 단위원 어디인지* 표시.
- **예상 공수**: 중 (풍경 + 그림자 동역학).
- **장점**: 책 스토리 100% 매칭, *닮음* 의 핵심 직관까지 학습.
- **단점**: 탄젠트 *함수* 의 동작 자체(점근선·주기)는 다소 약하게 노출.

### 안건 C — 경사도 디자이너 (현대 응용)
- **컨셉**: 도로·휠체어 경사로·롤러코스터 첫 언덕을 *각도/경사%* 로 설계.
- **메인 동선**: 슬라이더로 각도 변경 → 경사% 자동 계산 (tan θ × 100). 안전 기준 표(도로 8%, 휠체어 5%, 비상계단 30°)와 비교.
- **챌린지**: "1km 가면 100m 올라가는 도로의 각도는?" "20° 경사로의 % 는?" 같은 양방향 퀴즈.
- **확장 위젯**: *카메라 FOV 시뮬* — 시야각이 풍경 폭에 어떻게 매핑되는지.
- **예상 공수**: 중.
- **장점**: 실생활 밀착, 탄젠트의 *역할* 다양 노출.
- **단점**: 책 스토리(탈레스)와 거리.
