# 탄젠트함수 — 탈레스와 피라미드의 비밀

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 탄젠트함수 — *탈레스와 피라미드의 비밀* |
| **스토리 요약** | (※ 원문 확인 필요) BC 6세기 탈레스가 *그림자의 비례* 만으로 이집트 피라미드 높이를 알아낸 일화. 자기 키와 그림자 길이의 비 = 피라미드 높이와 그림자 길이의 비. 닮음과 탄젠트의 만남. |
| **핵심 수학** | tan θ = 대변/인접변 = sin θ / cos θ · 점근선(±π/2) · 닮음의 비례 · 경사도(%) |

## 교과 맥락

- **한국 정규 교과**: 탄젠트 함수 = 중3 ~ 고2. 그러나 **탈레스의 그림자 활동은 한국 초등 과학·수학 교육에 정식 등장** ([소년한국일보 — 초등학생 수학실험 365: 피라미드 높이를 어떻게 측정했을까요?](https://www.kidshankook.kr/news/articleView.html?idxno=12189))
- **닮음·비례**: 초등 5~6학년의 *비와 비례* 단원에서 정식 학습
- **결론**: ⭐ **9개 단원 중 초등 적합성이 가장 높음.** 닮음 직관만으로 핵심에 도달, 정식 활동 자료가 풍부.

## 학습 목표

1. 같은 시각, 모든 사물의 *높이/그림자* 비는 같다는 닮음 원리
2. 그래서 *내 그림자* 로 피라미드의 높이를 알 수 있다는 탈레스의 통찰
3. 탄젠트 = sin/cos = 대변/인접변, 일상의 경사도(%)와 같음

## 관련 사이트 내 퍼즐

- (사인·코사인) — 단위원 자산 재사용 (점근선 처리)
- `linear-function` — *기울기 = tan(직선의 기울기각)*
- `squares` — 닮음의 기하적 직관 보조

## 수학퍼즐 후보 조사

### 후보 1 — 탈레스 측량가 (그림자로 높이 재기) 🌅
- **퍼즐 정의**: 사용자 = 탈레스. 자기 키와 그림자 + 피라미드 그림자 → 피라미드 높이 추정.
- **풀이 흐름**: 풍경 일러스트 + 두 그림자 길이 슬라이더. 자동으로 *닮음 비례식* 표시 → 피라미드 높이 자동 계산
- **선례**: 한국 *초등학생 수학실험 365* 정식 활동. [Think Academy lesson](https://www.thethinkacademy.com/blog/edubriefs-thales-and-the-pyramid-measuring-height-with-shadows/) + GeoGebra Similar Triangles 등 다수.
- **초등 적합성 ★★★ (단원 중 최고)**: 추천. **한국 초등 정규 교육 활동**. 4~6학년 단독 풀이 가능. 비례식만 알면 풀림. 책 스토리 100% 매칭.

### 후보 2 — 그림자 시계 ⏰
- **퍼즐 정의**: 시간(아침→낮→저녁) 슬라이더로 해의 위치를 바꾸면 *물체와 그림자 길이 비* (= tan)가 변화. 탄젠트의 *시간 함수* 시각화.
- **풀이 흐름**: 시간 슬라이더 → 그림자 길이 변화 → "정오에 그림자가 가장 짧은 이유?" 발견
- **선례**: 해시계(sundial) lesson plan 다수. 초등 사회·과학에 등장.
- **초등 적합성 ★★★**: 추천. 일상 경험과 연결, *시간*은 친숙. 3~6학년 가능. 사회/과학 통합 학습 효과.

### 후보 3 — 경사로 디자이너 (현대 응용) 🛣️
- **퍼즐 정의**: 도로·휠체어 경사로·롤러코스터 첫 언덕을 *각도/경사%* 로 설계. 안전 기준(도로 8%, 휠체어 5%) 표와 비교.
- **풀이 흐름**: 슬라이더로 각도 변경 → 경사% 자동 계산(tan θ × 100) → 안전 판정
- **선례**: 도시 공학·접근성 가이드라인 다수. *건설기준* 자료에 등장.
- **초등 적합성 ★★**: 부분 적합. *경사도* 개념이 5~6학년에는 약간 추상. 그래프 없이 *몇 도면 휠체어가 갈 수 있나?* 식 시각화면 ★★★.

### 후보 4 — 점근선 발견 시뮬 ⚠️
- **퍼즐 정의**: 단위원에서 θ를 90°에 가까이 가져가면 *탄젠트가 무한대로 폭발* 하는 모습 시각.
- **풀이 흐름**: θ 슬라이더 → 단위원에서 직각변비 → tan 그래프 무한대 → "왜?" 발견
- **선례**: PhET Trig Tour 의 점근선 표시. *수학에서 무한대* 의 첫 만남.
- **초등 적합성 ★**: 어려움. 무한대·점근선 추상. 중학생 이상. 한 컷 시연이면 가능.

### 후보 5 — 에라토스테네스 지구 둘레 측정 🌍
- **퍼즐 정의**: BC 240년 에라토스테네스가 *그림자 각도 7.2°* 와 *알렉산드리아-시에네 거리* 만으로 지구 둘레를 알아냄. 사용자가 같은 방법으로 추정.
- **풀이 흐름**: 두 도시 그림자 차이 입력 → 둘레 자동 계산 → 실제 값과 오차 확인 (1.5% 이내 가능)
- **선례**: [sciencelove.com](https://sciencelove.com/1120), [Javalab](https://javalab.org/en/measuring_the_earth_en/), [경향신문](https://www.khan.co.kr/article/200703130926391) 등 한국 자료 다수. 정식 과학 단원 활동.
- **초등 적합성 ★★★**: 추천. 한국 초등 *과학* 단원에 정식 등장. 비례 직관만으로 풀이 가능. 4~6학년 가능. 역사·천문·수학 통합.

### 후보 6 — 빌딩 높이 측정 (스마트폰 풍) 📱
- **퍼즐 정의**: "스마트폰 측정 앱" 흉내. 빌딩 앞에서 *각도기로 꼭대기 보고* + *발걸음으로 거리 잰* 다음 → 높이 자동 계산.
- **풀이 흐름**: 거리 입력 → 각도 입력 → tan 으로 높이 계산
- **선례**: 일상 측정 앱 (TheodoLite, Smart Measure). lesson plan 다수.
- **초등 적합성 ★★**: 부분 적합. 각도기 사용은 4~5학년부터 가능, 식까지는 부담. 6학년 + 도움말 시 ★★★.

### 후보 7 — tan 그래프 카드 매칭 🃏
- **퍼즐 정의**: tan 그래프 카드 + 각도 카드 매칭.
- **풀이 흐름**: 그래프 보고 각도 선택 → 정오답
- **선례**: 표준 trig matching.
- **초등 적합성 ★**: 어려움. 식·점근선 부담. 비추.

## 수학의 원리 탭 구현 계획

### 핵심 개념 4개

1. **닮은 삼각형의 비밀**
   - 직관: "큰 삼각형이든 작은 삼각형이든, 같은 모양이면 *변의 비* 가 같다"
   - 시각: 같은 각도의 직각삼각형 3개 (다른 크기) → *높이/밑변* 비 모두 동일
   - 자가 점검: 두 삼각형이 닮았으면 같은 것은? (= 모든 변의 비)

2. **그림자의 마법 (탈레스)**
   - 직관: 같은 시각에는 모든 사물의 *높이/그림자* 비가 같음 — 해가 같으니까!
   - 시각: 사람과 피라미드의 그림자 + 비례식
   - 일상의 응용: 나무·빌딩·산

3. **탄젠트 = 사인 ÷ 코사인**
   - 직관: 대변/인접변 = (대변/빗변) ÷ (인접변/빗변)
   - 시각: 같은 단위원에서 sin·cos·tan 동시 마커
   - 라기 좋은 식: tan = sin/cos

4. **경사로 (일상 속 탄젠트)**
   - 8% 경사 = tan 4.6°
   - 도로·휠체어·등산로 — 어디서 만나나
   - 시각: 5%·10%·30°·45° 비교 카드

### 시각화 자산
- `CoordPlane` 재사용 (점근선 처리 옵션)
- `UnitCircle` 재사용
- 그림자 풍경 일러스트 (단원 전용, 후보 1·2)

### 자가 점검 질문
1. tan 45° = ? (= 1)
2. 8% 경사도는 약 몇 도인가? (≈ 4.6°)
3. 내가 1m, 그림자가 2m, 나무 그림자가 12m 일 때 나무 키는? (= 6m)
