# 학습 시간 메타 표준

각 퍼즐·단원에 *예상 학습 시간* 을 부착하면 사용자가 *오늘 짧게 1편*
또는 *주말에 깊게 1편* 같은 선택을 할 수 있다. 본 문서는 그 메타데이터의
필드 형태·기본값·표시 위치·산정 가이드를 표준화. **본 문서는 표준 정의.
실제 인터페이스 변경·렌더링 적용은 사용자 결정 후 수행**.

## 1. 필드 형태 (3안 비교)

`PuzzleCard` 인터페이스에 추가될 새 필드 후보.

### 안 1 — 문자열 자유 입력
```ts
estimatedTime?: string; // 예: "5~10분", "약 15분", "30분 이상"
```
- ✅ 직관적, 표현력 높음
- ❌ 정렬·필터링 어려움, 표기 통일성 떨어짐

### 안 2 — 분 단위 범위 객체
```ts
estimatedTime?: { min: number; max: number }; // 분 단위
```
- ✅ 정렬·필터·평균 계산 가능
- ✅ 표시 시 `${min}~${max}분` 으로 일관 포맷
- ❌ 객체라 작성 시 약간의 비용

### 안 3 — 분 단위 단일값
```ts
estimatedTime?: number; // 분 단위 평균
```
- ✅ 가장 단순, 정렬 즉시 가능
- ❌ "5~10분" 같은 *느슨한 추정* 을 표현 못 함

**추천**: **안 2** — 표현력 + 데이터 다루기 균형. 카드 표시는 `5~10분`,
필터는 `min ≤ N ≤ max` 로.

## 2. 기본값 (필드 미설정 시)

`difficulty` 기반 폴백:

| difficulty | 기본 표시 | 근거 |
|------------|-----------|------|
| easy | `5~10분` | 단순 발견·탐험 페이지 평균 |
| medium | `10~20분` | 단계별 퀴즈/조작 평균 |
| hard | `20~30분` | 다단계 추론·전략 |

폴백은 *카드 표시* 시점에 적용 (데이터에 박지 않음 — 정확한 값으로 덮어쓰기 가능).

## 3. 표시 위치 (3곳)

### 카드 (`/puzzles`, `/principles` 그리드)
- 위치: 카드 우상단 또는 difficulty 배지 옆
- 형태: `⏱ 5~10분` (시계 이모지 + 범위)
- 폰트: 기존 `.difficulty` 와 같은 톤, 약간 옅게

### 페이지 헤더 (`StoryHeader` 확장)
- 위치: 핵심 수학 배지 줄 옆 또는 그 아래
- 형태: `⏱ 예상 학습 시간 5~10분`
- 신규 슬롯: `StoryHeader` 의 `estimatedTime` prop 추가 (옵셔널)

### 사이드바·메인 페이지 카드
- 위치: 동일 형태로 카드 컴포넌트가 있다면 동일 슬롯
- 미적용 가능 (정보 밀도 우선시 시)

**추천**: 카드 + 페이지 헤더 두 곳 표시. 카드에서는 *결정에 도움*,
페이지에서는 *시작 전 마음 준비*.

## 4. 시간 산정 가이드 (단원 작성자용)

새 단원의 `estimatedTime` 을 정할 때:

| 페이지 요소 | 시간 가산 |
|-------------|-----------|
| 스토리 인트로 읽기 | +1분 |
| 단일 인터랙티브 위젯 (슬라이더 1~2개) 탐색 | +3~5분 |
| 단계별 퀴즈 (3~5문제) | +5~8분 |
| 코딩 탭 / 표 학습 | +3~5분 |
| 게임/시뮬 클리어 또는 미션 1개 | +5~10분 |
| 자동 풀이/시뮬 관찰 | +2~3분 |

탐험 모드만 있는 단원: 합산이 5~10분 → `easy`/`medium` 권장.
3탭 구조 (linear-function 형) : 보통 **10~20분** → `medium`.
다단계 미션 게임 (예: 단원 1 안건 B 포탄): **15~25분** → `medium~hard`.

## 5. 함수 커리큘럼 9단원 사전 추정 (참고용 초안)

기획문서의 *1차 추천 안건* 기준. 단원 시작 시 실제 구현에 맞춰 조정.

| # | 단원 | 추천 안건 | 추정 시간 | difficulty |
|---|------|-----------|-----------|-----------|
| 1 | 이차함수 | B 포탄 발사 | 15~25분 | medium |
| 2 | 다항함수 | B 곡선 통과시키기 | 12~20분 | medium |
| 3 | 지수와 로그 | B+C 결합 | 15~25분 | medium |
| 4 | 벡터 | B 비행기 항로 | 15~25분 | medium |
| 5 | 사인 | A 단위원+파동 | 10~18분 | medium |
| 6 | 코사인 | B 천문 삼각측량 | 15~22분 | medium |
| 7 | 탄젠트 | B 탈레스 측량가 | 12~20분 | medium |
| 8 | 미분 | B 롤러코스터 속도계 | 15~25분 | medium |
| 9 | 적분 | A+C 결합 | 18~28분 | medium~hard |

(평균 ~17분/단원, 9단원 총 약 2.5시간)

## 6. 후속 작업 (옵션 결정 후)

표준 채택 후 자동 수행 가능:
- `PuzzleCard` 인터페이스에 `estimatedTime?: { min: number; max: number }` 추가
- 기존 32개 퍼즐 카드에 difficulty 폴백 표시만 적용 (값 채우지 않아도 동작)
- 카드 컴포넌트 (puzzles/principles 그리드 셀) 에 `⏱` 배지 추가
- `StoryHeader` 컴포넌트에 `estimatedTime` prop 슬롯 추가
- 단원 1~9 신규 등록 시 정확한 값 입력 (위 표 참조)
