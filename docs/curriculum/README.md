# 함수·해석학 커리큘럼 기획 인덱스

책 *『재미있는 〈수학〉 이야기』* 의 함수~적분 9개 단원을 인터랙티브 학습 콘텐츠로 옮기기 위한 단원별 기획문서 모음.

## 운영 방식

- 단원당 기획문서 1개 — **여러 구현 안건(A/B/C)** 을 병렬 제시
- 매주 사용자가 **안건 1개를 선정** → 해당 안건의 구체 구현 계획으로 확장 → 코드화
- 기획문서는 *살아있는 문서* — 결정·변경 사항은 해당 단원 파일에 누적

## 공통 하네스 (표준 안건 A의 정의)

`linear-function`이 검증한 표준 형식 — 별도 명시 없으면 이 형태가 안건 A.

- **3탭 구조**: `탐험기` | `퀴즈` | `코딩`
  - 탐험기: 슬라이더로 매개변수 직접 조정 → 그래프 즉시 반응
  - 퀴즈: 단계별 발견 학습 (자동 생성 문제)
  - 코딩: 같은 수학을 코드(파이썬 의사코드 + 표) 로 표현
- **시각화**: SVG 좌표평면 (필요 시 `src/components/CoordPlane.tsx`로 승격해 공유)
- **로직**: `src/lib/puzzles/<unit>.ts` — 순수 함수 (퀴즈 생성, 좌표 변환, 포맷팅)
- **스토리**: 페이지 상단에 책 챕터 인용 카드 1개 (3~5문장)
