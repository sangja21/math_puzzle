# 적분 — 잘게 쪼갤수록 정확해진다

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 적분 — *잘게 쪼갤수록 정확해진다* |
| **스토리 요약** | (※ 원문 확인 필요) 곡선 아래 면적·곡면의 부피를 *직사각형(또는 도형)으로 잘게 잘게 쪼개* 더한 뒤 무한히 잘게 만들면 정확. **아르키메데스의 구분구적법(실진법)** 의 정신. |
| **핵심 수학** | 구분구적법 · 정적분 ∫f(x)dx · 미적분의 기본정리(FTC) · 회전체 부피 |

## 교과 맥락

- **한국 정규 교과**: 적분 = **고등학교 미적분** ([나무위키 — 적분](https://namu.wiki/w/%EC%A0%81%EB%B6%84))
- **초등·중학교**: *넓이 계산* 자체는 초등 4~5학년 정식 과목. 직사각형·삼각형·평행사변형 넓이.
- **결론**: 식·기호 ∫ 는 어려움. **그러나 *직사각형으로 곡선 아래 면적 추정* 은 초등 친화적.** 아르키메데스의 *포물선과 직선이 둘러싼 영역 = 내접 삼각형 4/3* 도 5~6학년이 *시각으로* 충분히 받아들임.

## 학습 목표

1. 곡선 아래 면적은 *작은 직사각형 합* 으로 어림할 수 있다 (구분구적법)
2. 직사각형을 *더 잘게* 쪼갤수록 더 정확하다 → 무한히 잘게 = 적분
3. 미분과 적분이 *서로 반대* 라는 미적분의 기본정리 (FTC)

## 관련 사이트 내 퍼즐

- `squares` — 1+3+5+...+(2n-1) = n². **이산판 적분 = 합의 닫힌 형태**. 본 단원의 *전제 직관* 으로 인용 강추
- (미분, 단원 8) — FTC로 직접 짝꿍
- `machin` — 급수의 적분식 (atan x = ∫dx/(1+x²)) 시작점

## 수학퍼즐 후보 조사

### 후보 1 — 분할 슬라이더 (직사각형 합) 📊
- **퍼즐 정의**: 곡선 아래 영역을 직사각형 N개로 근사. N 슬라이더로 *오차가 줄어드는* 모습 관찰.
- **풀이 흐름**: 함수 선택, 구간 [a,b], 분할 N(1→100→무한 토글). 좌·중·우 endpoint 비교
- **선례**: IntMath, GeoGebra(여러 버전), Math Open Reference 등 매우 풍부. 적분 도입의 표준.
- **초등 적합성 ★★★**: 추천. 직사각형 보고 *넓이 더하기* 는 4~6학년 친화. **N을 늘릴수록 정확해진다** 는 책 스토리 그대로. 식 불필요.

### 후보 2 — 면적 추정 게임 🎯
- **퍼즐 정의**: 임의 곡선 아래 *진짜 면적* 을 사용자가 추정해 입력. 분할 슬라이더로 정답에 접근.
- **풀이 흐름**: 곡선 표시 → 면적 추정 입력 → 슬라이더로 점진 정밀화 → 최종 점수
- **선례**: 위 표준 자산의 게임화 변형. 직접 동일 게임은 적음 — 신선함.
- **초등 적합성 ★★★**: 추천. 추정 → 검증 흐름이 학습적. 4~6학년 가능. 점수가 동기 부여.

### 후보 3 — 몬테카를로 면적 (점 던지기) 🎲
- **퍼즐 정의**: 사각형 안에 점을 무작위로 N개 던짐. *곡선 아래 점 / 전체 점* 비율 × 사각형 넓이 = 곡선 아래 면적 추정.
- **풀이 흐름**: 점 개수 슬라이더 → 점 흩뿌림 → 추정값 표시 → "더 많이 던질수록 더 정확해지나?" 발견
- **선례**: 몬테카를로 적분 — 표준 컴퓨터 그래픽스·통계 기법. lesson plan 다수 ([Wikipedia Riemann Sum](https://en.wikipedia.org/wiki/Riemann_sum) 변형)
- **초등 적합성 ★★★**: 추천. *확률 점 던지기* 가 직관적. 3~6학년 가능. *통계*와 자연 연결.

### 후보 4 — 회전체 부피 (3D) 🍷
- **퍼즐 정의**: 곡선을 그리고 *x축 기준으로 회전* 시키면 회전체 생성. 와인잔·꽃병 모양 부피 계산.
- **풀이 흐름**: 곡선 그리기 → "회전" 버튼 → 3D 회전체 + 부피
- **선례**: GeoGebra 회전체 도구, *Solid of Revolution* 표준 활동.
- **초등 적합성 ★**: 어려움. 3D 회전 + 부피 추론 부담. 중학생 이상. *결과만 보여주는 시연* 이면 가능.

### 후보 5 — FTC 동시 시각 (미·적분 짝꿍) 🤝
- **퍼즐 정의**: 좌측 함수 f, 우측 *누적 면적 함수* F(x). x를 슬라이드하면 F가 그려지고, F의 *기울기 = f값* 임을 강조.
- **풀이 흐름**: 함수 선택 → 슬라이더 누적 → "F'(x) = f(x) 임을 보세요" 토글
- **선례**: 표준 FTC 시각화 — Khan Academy, GeoGebra 등 다수.
- **초등 적합성 ★**: 어려움. 미분-적분 동시 추상. 중학생 이상. 단원 8을 마친 학생용 *마무리 한 컷*.

### 후보 6 — 아르키메데스 포물선 4/3 발견 🏛️
- **퍼즐 정의**: 포물선과 직선이 둘러싼 영역에 *내접 삼각형* 을 그림. 사이 빈틈에 *작은 삼각형* 두 개. 또 빈틈에 더 작은 삼각형 4개... 무한히 반복.
- **풀이 흐름**: 단계별 삼각형 추가 → 누적 넓이 → 포물선 면적의 4/3 에 *수렴* 발견
- **선례**: [MathPark 아르키메데스 실진법](https://www.mathpark.com/545), [한경 생글생글](https://sgsg.hankyung.com/article/2024053163531). 한국어 청소년 자료 다수.
- **초등 적합성 ★★**: 부분 적합. 삼각형 추가 자체는 4~6학년 가능, *4/3 라는 정확한 수치 발견* 은 부담. 6학년 + 도움말 시 ★★★. 책 스토리(아르키메데스) 와 완벽 매칭.

### 후보 7 — 면적 비교 카드 게임 🃏
- **퍼즐 정의**: 곡선 아래 영역 그림 4~6장. 면적이 가장 큰/작은 것 추측 → 정답 공개 (적분 계산 결과).
- **풀이 흐름**: 그림 보고 추측 → 정답
- **선례**: 표준 visual estimation 게임 변형.
- **초등 적합성 ★★★**: 추천. *눈대중* 만으로 풀 수 있음. 3~6학년 가능. 직관 훈련.

## 수학의 원리 탭 구현 계획

### 핵심 개념 4개

1. **곡선 아래 면적 — 어떻게 잴까?**
   - 직관: "직사각형이면 가로 × 세로, 곡선이면?"
   - 시각: 곡선 아래에 직사각형 1개 → 넓게 어림

2. **잘게 쪼개면 더 정확**
   - 직관: 직사각형을 N=4 → 10 → 100 → 1000 으로 늘림
   - 시각: 분할 슬라이더, 오차 막대 표시
   - 핵심 한 줄: "무한히 잘게 = 적분"

3. **아르키메데스의 통찰 (역사)**
   - 직관: BC 250년 아르키메데스가 *포물선 면적 = 내접 삼각형의 4/3* 발견
   - 시각: 한 컷 — 삼각형 + 빈틈에 더 작은 삼각형
   - 메시지: 적분의 *원형* 이 2,300년 전에 이미 시작

4. **미분과 적분은 짝꿍 (FTC)**
   - 직관: 미분이 "쪼개기" 라면 적분은 "모으기" — 서로 반대
   - 시각: f 와 F = ∫f 동시 그래프 (단원 8과 연계)
   - 한 컷 시연

### 시각화 자산
- `CoordPlane` 재사용
- `src/lib/puzzles/calculus.ts` 재사용 (단원 8과 공유) — 사다리꼴 적분, 구분구적법 헬퍼
- 회전체 (선택) — 단순 3D 또는 단면 슬라이스 시각

### 자가 점검 질문
1. 가로 5, 세로 3의 직사각형 면적은? (= 15)
2. 곡선 아래 면적을 *어림* 하려면 무엇을 잘게 쪼개나? (= 직사각형 또는 도형)
3. 아르키메데스가 발견한 *포물선 면적과 내접 삼각형* 의 비는? (= 4 : 3)
