# 적분 — 잘게 쪼갤수록 정확해진다

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 적분 — *잘게 쪼갤수록 정확해진다* |
| **스토리 요약** | (※ 원문 확인 필요) 곡선 아래 면적·곡면의 부피를 *직사각형(또는 도형)으로 잘게 잘게 쪼개* 더한 뒤 무한히 잘게 만들면 정확해진다는 발상. 구분구적법의 정신. |
| **핵심 수학** | 구분구적법 · 정적분 ∫f(x)dx · 미적분의 기본정리(FTC) · 회전체 부피 · 곡선 길이 |
| **학습 목표** | ① 면적 계산을 *합* 의 극한으로 보는 발상 ② 적분과 미분이 *역연산* 임을 시각으로 ③ 자연·공학 양에서 적분이 어떻게 등장하는지(거리·일·전하량 등) |

## 관련 수학퍼즐 조사

### 사이트 내 연관 퍼즐
- `squares` — 1+3+5+...+(2n-1) = n². **이산판 적분 = 합의 닫힌 형태**. 본 단원의 *전제 직관* 으로 인용 강추.
- `differential` (단원 8) — FTC로 직접 짝꿍.
- `machin` — 급수의 적분식 (atan x = ∫dx/(1+x²)) 시작점.
- `sieve` — 무관.

### 외부 클래식 퍼즐·사례
- **아르키메데스의 원기둥-구 비율** (BC 250년경) — 그의 묘비에 새겨졌다고 전해짐. *고대 적분*.
- **카발리에리의 원리** (1635) — 단면적이 같으면 부피도 같다.
- **케플러의 술통 부피** — 적분의 산업적 출발.
- **포물선 아래 면적** — 아르키메데스의 *소진법(method of exhaustion)*.
- **확률 분포의 면적 = 1** — 통계학으로의 다리.
- **건축의 단면-부피** — 일상 응용.

## 구현 안건

### 안건 A — 표준 하네스 (직사각형 분할 슬라이더)
- **컨셉**: 곡선 아래 영역을 직사각형 N개로 근사. N 슬라이더로 *오차가 줄어드는* 모습 관찰.
- **탐험기**: 함수 선택(다항·sin·exp), 적분 구간 [a,b], 분할 수 N (1→100→무한 토글). *왼쪽합·오른쪽합·중점합·사다리꼴* 비교.
- **퀴즈**: (1) N→∞이면 면적은? (2) 위·아래 합의 가운데 정도가 정확한가? (3) ∫₀¹ x dx = ?
- **코딩 탭**: 사다리꼴 적분 의사코드 (몬테카를로 보너스).
- **예상 공수**: 중 (직사각형 동적 렌더링).
- **장점**: 적분의 *정의* 를 가장 정직하게 보여줌.
- **단점**: 책 스토리(잘게 쪼개기)와 직결되지만 응용감은 약함.

### 안건 B — 면적·부피 측량 도구
- **컨셉**: 임의로 그린 곡선 아래 면적을 분할 슬라이더로 추정. *3D 모드* 에서는 곡선을 회전체로 만들어 부피.
- **메인 동선**: 곡선 그리기 (점 드래그) → 분할로 면적 → "회전" 버튼 → 회전체 3D + 부피.
- **챌린지**: "이 와인잔의 부피는?" 류 응용 카드 — 잔의 단면 곡선을 그려 회전체로 부피 계산.
- **아르키메데스 모듈**: 원기둥에 *내접* 한 구의 부피비 2/3 시연 — 책 챕터의 거대 사례.
- **예상 공수**: 중~대 (3D 회전체 시각화).
- **장점**: 적분의 응용 폭 넓게 노출, 시각 임팩트 강함.
- **단점**: 3D 시각화는 구현 부담.

### 안건 C — FTC 동시 시각화 (미분-적분 한 화면)
- **컨셉**: 좌측에 함수 f, 우측에 그 *누적 면적 함수* F(x) = ∫f. x를 좌측에서 슬라이드하면 우측 그래프가 *그려진다* — 그리고 우측 곡선의 기울기가 좌측 f값임을 강조 → FTC.
- **메인 동선**: 함수 선택 → 슬라이더로 누적 → "F'(x) = f(x) 임을 직접 보세요" 토글.
- **단원 8과의 연결**: 본 페이지에서 단원 8 미분의 접선 화면 모드를 토글로 불러올 수 있게 → *형제 페이지*.
- **예상 공수**: 중 (누적 면적 동기화 애니메이션).
- **장점**: 미적분 학습의 정점인 *FTC* 를 가장 명료하게. 단원 8과 짝을 이룸.
- **단점**: "잘게 쪼개기" 라는 책 스토리의 *직관* 은 안건 A보다 약함.

## 추천

- **1차 추천: 안건 A + 안건 C 결합** — *잘게 쪼개기*(책 스토리·정의)는 메인 탭으로 A, FTC는 두 번째 탭으로 C. 두 탭이 단원 8과 *시리즈 마무리* 효과를 만들어 커리큘럼의 종착점다움.
- **속도 우선 시**: 안건 A 단독 + 마지막 섹션 한 컷에 *"단원 8과 합치면 FTC"* 미니카드.
