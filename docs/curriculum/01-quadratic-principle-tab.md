# 이차함수 — 수학의 원리 탭 구현 계획서

## 컨텍스트

- **소속 단원**: 단원 1 — 이차함수 (`/puzzle/quadratic-function`)
- **이 탭의 역할**: 포탄쏘기 게임 탭에서 일어나는 일을 *이해* 하기 위한 수학적 배경 제공. 원리 탭만 봐도 자기완결적 학습이 가능해야 하고, 게임 탭과 *교차 학습* 도 매끄러워야 함.
- **읽는 사람**: 초·중등 학생 (이차함수 식을 처음 접하는). 식을 외우는 게 아니라 *시각으로 발견* 하도록.
- **분량 가이드**: 한 화면에서 위→아래 6개 섹션을 스크롤로 통과. 각 섹션은 *짧은 한 단락 + 인터랙션 + 자가 점검 한 줄*.
- **선행 자산**: `CoordPlane` (이미 추출됨), `StoryHeader` (이미 추출됨).

## 섹션별 상세 (콘텐츠 + 인터랙션 + 검증)

### § 1. 포물선이란?

**도입 텍스트 (draft)**:
> 공중으로 던진 공이 그리는 자취, 분수에서 솟는 물줄기, 자동차 헤드라이트의 반사면 ─ 이 모양들에는 공통점이 있어요. 모두 **포물선** 이라는 같은 곡선을 따라 움직입니다.

**시각**: 사진/일러스트 카드 4장 (CSS grid 2×2)
- 분수
- 농구 슛 궤적
- 다리 아치
- 포탄 발사

각 카드 위에 *포물선 곡선 오버레이* (SVG path 한 가닥).

**인터랙션**: 카드 hover 시 곡선 강조 (scale/opacity), 클릭 시 짧은 한 줄 설명 ("분수는 물 입자가 중력 때문에 포물선을 그리며 떨어져요").

**자가 점검**:
- Q: 다음 중 포물선이 *아닌* 것은? ① 분수 물줄기 ② 똑바로 떨어지는 빗방울 ③ 던진 공
- A: ②

---

### § 2. y = x² — 가장 단순한 포물선

**도입 텍스트**:
> 모든 포물선의 *원형* 은 y = x² 입니다. x에 어떤 수를 넣든 y는 그 수의 제곱. -3을 넣어도, +3을 넣어도 y는 9. 그래서 그래프가 *좌우 대칭* 이에요.

**시각**: `CoordPlane`
- xRange [-5, 5], yRange [-1, 12]
- 곡선: y = x² (`sampleFunction(x => x*x, -5, 5)`)
- 마커 점: (-2, 4), (-1, 1), (0, 0), (1, 1), (2, 4) — 표와 색 동기

**보조 표**: 옆에 4행 표
| x | y = x² |
|---|--------|
| -2 | 4 |
| -1 | 1 |
| 0 | 0 |
| 1 | 1 |
| 2 | 4 |

**인터랙션**: 표 행 hover 시 해당 점이 그래프에서 깜빡임. 추가 인터랙션 없음 (정적 발견).

**자가 점검**:
- Q: y = x² 그래프에서 (-3, ?) 의 ? 는?
- A: 9

---

### § 3. a 가 바꾸는 것 — 가파름과 뒤집힘

**도입 텍스트**:
> y = ax² 의 a 는 포물선의 *가파름* 을 정해요. a 가 클수록 가파르고, a 가 0보다 작으면 그래프가 *뒤집혀* 위로 솟구치지 않고 아래로 떨어져요.

**시각**: `CoordPlane`
- 곡선 1개: y = ax² (a 값에 따라 동적)
- 보조 곡선: y = x² (a=1) 점선 회색 — 비교용

**인터랙션**:
- 슬라이더: a, 범위 [-3, 3], step 0.5
- 슬라이더 위에 *현재 식 표시*: "y = 2x²" 같은 형태
- 슬라이더 아래에 a 부호별 칩 (3종): "a > 0: 위로 볼록", "a = 0: 직선!", "a < 0: 아래로 뒤집힘"

**상태**:
```ts
const [a, setA] = useState(1);
const baseLine = sampleFunction(x => x*x, -5, 5);     // 점선 비교
const aLine    = sampleFunction(x => a*x*x, -5, 5);   // 동적
```

**자가 점검**:
- Q: a = -2 일 때 그래프는 어느 쪽으로 볼록?
- A: 아래로 (∩ 모양)

---

### § 4. c 가 바꾸는 것 — 위·아래 이동

**도입 텍스트**:
> y = x² + c 의 c 는 그래프 *전체* 를 위·아래로 옮겨요. c 가 +3 이면 위로 3칸, c 가 -2 이면 아래로 2칸. 모양은 그대로, 자리만 달라져요.

**시각**: `CoordPlane`
- 곡선: y = x² + c (c 값에 따라 위·아래)
- 보조: y = x² (c=0) 점선

**인터랙션**:
- 슬라이더: c, 범위 [-5, 5], step 1
- 화면에 *y절편 마커* 강조: "(0, c)"

**자가 점검**:
- Q: y = x² + 4 가 y축과 만나는 점은?
- A: (0, 4)

---

### § 5. 꼭짓점 — 포탄이 가장 높은 자리

**도입 텍스트**:
> 포탄이 *가장 높이* 올라간 그 한 점을 **꼭짓점** 이라고 해요. 위로 볼록한 그래프(a > 0의 *반대*)에서는 꼭짓점이 *최고점*, 아래로 볼록한 그래프(a > 0)에서는 꼭짓점이 *최저점* 이에요.

**시각**: `CoordPlane`
- 곡선: y = a(x-h)² + k (꼭짓점이 (h, k))
- 꼭짓점 마커: 빨간 원 + "꼭짓점 (h, k)" 라벨

**인터랙션**:
- 슬라이더 2개: a (-3~3), 꼭짓점 위치 (h, k) 드래그 (CoordPlane 위 드래그)
- *드래그 가능한 꼭짓점* 컴포넌트 신규 — onMouseDown/onMouseMove/onMouseUp

**자가 점검**:
- Q: y = x² + 4 의 꼭짓점은?
- A: (0, 4) — h=0, k=4

---

### § 6. x절편(근) — 포탄이 떨어지는 자리

**도입 텍스트**:
> 포탄이 *땅에 떨어지는 자리* — 그래프가 x축과 만나는 점을 **x절편** 또는 **근** 이라고 해요. 한 번도 안 닿을 수도 있고, 살짝 스칠 수도 있고, 두 번 닿을 수도 있어요.

**시각**: 카드 3장 (CSS grid 1×3 또는 가로 슬라이더)
- 카드 1: 근 2개 — y = x² - 4 (x절편 -2, 2)
- 카드 2: 근 1개 — y = x² (x절편 0 한 번)
- 카드 3: 근 0개 — y = x² + 4 (안 만남)

각 카드 안에 미니 `CoordPlane` (xRange [-5, 5], yRange [-5, 8], width 200, height 160).

**인터랙션**: 카드 클릭 시 큰 화면으로 확대 (모달 또는 가운데 강조). 또는 카드별 *근의 좌표* 토글 표시.

**자가 점검**:
- Q: y = x² + 4 의 근은 몇 개?
- A: 0개 (그래프가 x축과 만나지 않음)

// y = ax² + bx + c 평가
export function evaluateQuadratic(a: number, b: number, c: number, x: number): number {
  return a * x * x + b * x + c;
}

// 꼭짓점 좌표 (h, k) 반환
export function vertex(a: number, b: number, c: number): { x: number; y: number } {
  if (a === 0) return { x: 0, y: c };  // 직선
  const x = -b / (2 * a);
  return { x, y: evaluateQuadratic(a, b, c, x) };
}

// 근 — 0/1/2개
export type Roots =

각 섹션 끝의 *자가 점검* 6개를 페이지 하단에 *진척도 바* 로 한 번 더 모아 보여주는 것도 가능 (선택 기능).

## 포탄쏘기 게임 탭과의 교차 학습

- 원리 § 5 (꼭짓점) → 게임의 *최고 도달점* 과 매핑
- 원리 § 6 (근) → 게임의 *착탄 지점* 과 매핑
- 게임에서 실패 시 "원리 § 3 (a) 부분 다시 보기" 같은 힌트 링크
