# 지수와 로그 — 두 배의 두 배의 두 배

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 지수와 로그 — *(체스판 쌀알 류의 두 배 이야기)* |
| **스토리 요약** | (※ 원문 확인 필요) 한 칸에 1톨, 다음 칸에 2톨, 그 다음 4톨... 체스판 64칸이면 천문학적 양. 지수 폭증의 충격을 도입. |
| **핵심 수학** | aˣ · log_a x · 자연상수 e · 지수↔로그 역함수 · 로그 스케일 |

## 학습 목표

1. *선형 직관* 과 *지수 직관* 의 차이 체험 (한 톨씩 vs 두 배씩)
2. 로그 = "몇 번 곱했나" 의 또 다른 이름
3. 자연·기술 곳곳에 지수·로그가 숨어 있음 (복리, 박테리아, pH, 데시벨)

## 관련 사이트 내 퍼즐

- `collatz` — 짝수면 ÷2, 홀수면 ×3+1. 로그 그래프로 보면 핵심이 드러남
- `hanoi` — 디스크 N개 = 2ⁿ - 1 회 이동. 지수의 가장 유명한 알고리즘 사례
- `fakecoin` — 삼진 탐색 O(log₃ N), 로그의 알고리즘 사례

## 수학퍼즐 후보 조사

### 후보 1 — 체스판 쌀알 시뮬레이터 ♟️🌾
- **퍼즐 정의**: 체스판 8×8. "다음 칸" 버튼으로 한 칸씩 채우면 누적 쌀알 수가 표시. 32칸쯤에서 화면이 못 다 그릴 만큼 커짐 → *척도 변환* 토글로 로그 축 발견.
- **풀이 흐름**: 다음 칸 → 누적 쌀알 → "이게 얼마야?" 비유 (밥그릇/트럭/지구 생산량) → 64칸까지 도달 챌린지
- **핵심 수학**: 1, 2, 4, 8... = 2ⁿ. 누적 = 2ⁿ⁺¹ - 1
- **초등학생 적합성 ★★★**: 추천. 충격이 가장 강함, 식 몰라도 "와 너무 많아!" 가능. 3~6학년 모두 가능.

### 후보 2 — 종이접기 척도 사다리 📄
- **퍼즐 정의**: 0.1mm 종이를 한 번씩 접을 때마다 두께 두 배. 접은 횟수 슬라이더(0~50). 우측엔 *대수 자(scale ladder)* — 박테리아·사람키·에베레스트·달까지·태양·은하.
- **풀이 흐름**: 슬라이더 이동 → 두께 갱신 → 자에서 어디인지 마커 표시 → "달까지 가려면 몇 번 접어야 할까?"
- **핵심 수학**: 2ⁿ × 0.1mm 의 폭발, 로그 스케일 직관
- **초등학생 적합성 ★★★**: 추천. 시각적 충격, 자(尺) 비유가 강력. 4~6학년 가능. 자(尺) 단위 변환은 어른 도움 한 번이면 OK.

### 후보 3 — 복리 vs 단리 비교 💰
- **퍼즐 정의**: 100만원을 연 10% 로 30년 동안. 단리 vs 복리 두 그래프를 같이 그려 차이를 시각화.
- **풀이 흐름**: 연수 슬라이더 → 두 그래프 같이 늘어남 → 30년 차이 보면 "엥?" 충격
- **핵심 수학**: 단리 = 1차, 복리 = 지수
- **초등학생 적합성 ★★**: 부분 적합. *돈* 이 동기 부여이지만 "이자" 개념이 4~5학년에겐 낯설 수 있음. 6학년~중1 추천.

### 후보 4 — 박테리아 분열 시뮬 🦠
- **퍼즐 정의**: 박테리아 1마리 → 20분 후 2마리 → 40분 후 4마리... 시간 슬라이더로 N분 후 개체수 시각.
- **풀이 흐름**: 시간 슬라이더 → 점이 늘어남 + 카운트 → "1시간에 몇 마리?"
- **핵심 수학**: 2^(t/20) 지수 증가
- **초등학생 적합성 ★★★**: 추천. 점이 늘어나는 *애니메이션* 자체가 직관. 3~6학년 모두 가능.

### 후보 5 — 데시벨·리히터 카드 매칭 🔔
- **퍼즐 정의**: "도서관 30dB / 대화 60dB / 콘서트 110dB" 카드와 *실제 소리 크기 비율* 카드 매칭. 30→60은 1000배, 60→110은 10만배.
- **풀이 흐름**: 카드 짝맞추기 → 비율 충격 → 로그 스케일이 *왜 필요한지* 발견
- **핵심 수학**: log₁₀ 스케일이 거대 비율을 작은 숫자로 압축
- **초등학생 적합성 ★★**: 부분 적합. 비율 곱셈이 4~5학년에겐 어려움. *결과만 충격* 으로 노출이면 ★★★.

### 후보 6 — 로그 사다리 게임 🪜
- **퍼즐 정의**: 사다리 위에 *세로로 등간격* 칸. 1단=1, 2단=10, 3단=100, 4단=1000... 사용자가 *주어진 수* 가 어느 칸 사이에 있을지 클릭.
- **풀이 흐름**: "73,000은 몇 단과 몇 단 사이?" → 클릭 → 정오답
- **핵심 수학**: log 의 직관적 정의 — "10이 몇 번 곱해진 만큼"
- **초등학생 적합성 ★★**: 부분 적합. 자릿수 세기와 같은 사고이므로 *자릿수 게임* 으로 리프레임하면 ★★★.

## 수학의 원리 탭 구현 계획

### 핵심 개념 4개

1. **두 배씩 늘면 폭발한다 (지수)**
   - 직관: 체스판 쌀알, 종이접기
   - 시각: 1, 2, 4, 8, 16... 막대 그래프 (로그 축으로 토글 가능)

2. **반대로 줄이면 = 로그**
   - 직관: "몇 번 곱했더니 1000이 됐을까?"
   - 정의: log₁₀ 1000 = 3
   - 시각: 사다리 단 = log

3. **밑(base) 이 바뀌면**
   - 2배씩(컴퓨터) / 10배씩(과학) / e배씩(자연)
   - 시각: 같은 시간에 2ⁿ vs 10ⁿ vs eⁿ 비교 그래프

4. **자연·기술 속의 로그**
   - 데시벨·리히터·pH·별의 등급
   - 카드 5장으로 한 컷씩

### 시각화 자산
- `CoordPlane` 재사용 (단, *로그 축 옵션* 추가 필요 — `yScale: 'linear' | 'log'` prop)
- 척도 사다리 컴포넌트 신규 (단원 전용)

### 자가 점검 질문
1. 2를 10번 곱하면 약 얼마인가? (= 1024, 약 1000)
2. log₁₀ 100,000 은 얼마인가?
3. 리히터 6과 8의 지진 *세기 비율* 은? (= 100배)
