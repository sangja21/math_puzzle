## 관련 수학퍼즐 조사

### 사이트 내 연관 퍼즐
- `collatz` — 3n+1 시 폭증, /2 시 반감. *지수 스케일 로그 그래프*로 보면 핵심이 드러남. 본 단원과 직접적 시각 자산 공유 가능.
- `hanoi` — 디스크 N개의 최소 이동 = 2ⁿ - 1. 지수의 가장 유명한 알고리즘 사례.
- `machin` — 급수의 수렴 속도 = 로그적 정확도 증가.
- `fakecoin` — 삼진 탐색 O(log₃ N). 로그의 알고리즘 사례.
- `sieve` — 소수 분포 정리(π(n) ≈ n/ln n)와 연결 가능 (도입 한 줄로 인용).

### 외부 클래식 퍼즐·사례
- **체스판 쌀알 전설** — 1+2+4+...+2⁶³ ≈ 1.8×10¹⁹.
- **종이접기 달까지** — 0.1mm 종이를 43회 접으면 달까지 도달 (2⁴³ × 0.1mm ≈ 88만 km).
- **복리이자** — (1+r)ⁿ. e의 정의 (1+1/n)ⁿ → e.
- **박테리아 / 인구 증가** — 맬서스 모델.
- **리히터·데시벨·pH** — 로그 스케일의 일상.
- **소리·시각의 베버-페히너 법칙** — 인간 감각 자체가 로그.

## 구현 안건

### 안건 A — 표준 하네스 (지수·로그 그래프 토글)
- **컨셉**: 동일 그래프를 *선형↔로그 축 토글*. 같은 데이터가 한쪽에선 폭증, 한쪽에선 직선.
- **탐험기**: 밑 a 슬라이더 (0.5, 2, e, 10), 지수 그래프와 로그 그래프를 좌우 병치. 두 그래프가 *y=x 대칭*임을 시각.
- **퀴즈**: (1) 지수 함수의 y절편? (2) log₁₀ 1000 = ? (3) 같은 데이터를 어떤 축에 그리면 직선이 되는가?
- **코딩 탭**: 복리 계산 의사코드, 거듭제곱 vs 반복곱.
- **예상 공수**: 소~중 (로그 축 렌더링 추가 작업).
- **장점**: 표준 형식 유지, 두 함수의 *역함수 관계*를 한 화면에서 학습.
- **단점**: 두 그래프 병치는 신선하지만 다소 정적.

### 안건 B — 체스판 쌀알 시뮬레이터
- **컨셉**: 체스판 64칸을 한 칸씩 채워가며 누적량을 *선형·로그 두 축*으로 동시에 그래프화.
- **메인 동선**: "다음 칸" 버튼을 누르면 칸이 채워지고 누적 쌀알 수가 옆에 표시. 32칸쯤 가면 선형 축은 완전히 무용지물 → 로그 축의 필요성 *체감*.
- **단위 변환 게이지**: 1 → 10⁶ → 10⁹(국가 예산) → 10¹² → 10¹⁹ (전 지구 쌀 생산량)으로 누적량의 *척도*를 사용자에게 비유로 안내.
- **변형 모드**: 한 칸 = ×3? ×10? 으로 밑 변경 가능.
- **예상 공수**: 중 (시뮬 + 누적 그래프 + 척도 비유 텍스트).
- **장점**: 책 스토리와 100% 매칭. 지수의 *충격*을 가장 강하게 전달.
- **단점**: 로그 자체에 대한 학습은 부수적 — 별도 페이지나 탭으로 보강 필요.

### 안건 C — 종이접기 달까지 + 척도 사다리
- **컨셉**: 종이를 한 번씩 접을 때마다 두께가 두 배. 1번~50번까지 슬라이드 가능, *우주적 척도*와 비교.
- **메인 동선**: 슬라이더 = 접은 횟수. 우측에 두께를 *대수 자(scale ladder)* — 박테리아(μm) → 사람 키(m) → 에베레스트(km) → 달까지 거리 → 태양까지 → 알파 센타우리 → 우주의 끝.
- **로그 직관**: "각 단계는 두 배 = 자에서 한 칸"이라는 *로그 = 거듭제곱의 횟수* 체득.
- **반대 방향**: 같은 자에서 "리히터 지진 5 vs 7", "pH 3 vs 5", "데시벨 60 vs 90" 등 *생활 속 로그 스케일* 카드 노출.
- **예상 공수**: 중 (척도 사다리 그래픽이 핵심).
- **장점**: 지수와 로그를 *동일한 사다리* 위에서 양방향으로 보여줌. 학습 깊이 양호.
- **단점**: 게임성보다는 시연·관찰형 — 적극적 인터랙션이 적을 수 있음.

## 추천
