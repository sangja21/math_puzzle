# 코사인함수 — 지구에서 달까지의 거리

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 코사인함수 — *지구에서 달까지의 거리* |
| **스토리 요약** | (※ 원문 확인 필요) 직접 자로 잴 수 없는 *천문학적 거리* 를 두 관측점의 각도와 한 변 만으로 추정하는 기법(시차·삼각측량). 코사인 법칙과 측량의 이야기. |
| **핵심 수학** | cos θ = 인접변/빗변 · 사인과의 위상 차 (π/2) · **코사인 법칙** c² = a² + b² − 2ab·cos C · 시차(parallax) |
| **학습 목표** | ① 코사인의 기하 정의 ② 사인과 *위상 π/2 차이*인 형제임을 시각으로 ③ 코사인 법칙으로 직접 못 재는 변·각을 *유도* 하는 발상 ④ 천문 측량의 위대함 체험 |

## 관련 수학퍼즐 조사

### 사이트 내 연관 퍼즐
- `sine` (단원 5) — 동일한 단위원 자산을 그대로 사용. 사인을 90° 회전시킨 함수.
- `knight` — 격자 거리. 코사인 거리(코사인 유사도)와 약하게 연결 (벡터 단원 사용 시 자연스러움).

### 외부 클래식 퍼즐·사례
- **에라토스테네스의 지구 둘레 측정** (BC 240년경) — 두 도시의 그림자 각도 차이로 추정. 책 챕터의 *조상격* 사례.
- **별의 시차(parallax)** — 6개월 간격 지구 위치 변화로 별까지 거리 측정.
- **레이더·소나** — 거리·각도 측정.
- **코사인 법칙의 응용** — 삼각형 SAS / SSS 풀이.
- **GPS 삼각측량** — 다중 위성 거리.

## 구현 안건

### 안건 A — 표준 하네스 (코사인 그래프 + 단위원)
- **컨셉**: 사인 페이지의 단위원·파동 자산 *재사용*. 단위원 위 회전점의 *x좌표* 가 코사인 → 파동.
- **탐험기**: 사인 곡선과 코사인 곡선을 동일 화면에 겹쳐 → *π/2 차이* 발견.
- **퀴즈**: (1) cos 60° = ? (2) cos·sin 합의 항등식 sin²+cos²=1 시각 확인. (3) 코사인 법칙으로 변 c 구하기.
- **코딩 탭**: 코사인 거리 계산 (벡터 사이 각도).
- **예상 공수**: 소 (단위원 자산 재사용).
- **장점**: 사인 페이지와의 일관성, 학습 곡선 부드러움.
- **단점**: 책 스토리(달까지 거리)가 거의 등장하지 않음.

### 안건 B — 천문 삼각측량 시뮬레이터
- **컨셉**: 두 관측점에서 같은 천체(달·별)를 바라본 각도 → 거리 계산.
- **메인 동선**: 지도 위 두 관측점 A, B(예: 두 도시) 선택 → 각 점에서 달을 바라본 각도 입력 → AB 기선과 두 각으로 *코사인 법칙* 적용 → 달까지 거리 계산.
- **시각효과**: 두 직선이 만나는 점이 *달의 위치*. 슬라이더로 두 도시 사이 거리(기선) 변경 시 측정 정확도가 어떻게 바뀌는지 체험.
- **확장**: "이번엔 별의 시차로 거리 재기" — 6개월 간격 지구 위치를 두 관측점 삼아 별의 거리.
- **예상 공수**: 중 (지도 + 천문 시각화).
- **장점**: 책 스토리 100% 매칭, 코사인 법칙의 *위대함* 체득.
- **단점**: 단위 스케일이 어렵고(km, 광년) 입력값 검증이 까다로움.

### 안건 C — 코사인 법칙 도구박스 (실용)
- **컨셉**: SAS·SSS·SSA 등 삼각형의 *부분 정보* 만 주면 나머지를 구해주는 인터랙티브 도구.
- **메인 동선**: 모드 선택(SAS/SSS) → 슬라이더로 알려진 변·각 입력 → 미지의 변·각이 자동 계산되며 삼각형이 동적으로 그려짐.
- **응용 예**: "두 노선이 60° 각도로 갈라지고 각각 5km, 7km 가면 두 끝점 거리는?" 같은 응용 문제 카드.
- **예상 공수**: 중 (삼각형 동적 렌더링).
- **장점**: 실생활 응용 다양, 코사인 법칙 깊이 학습.
- **단점**: 책 스토리(달 거리)와 거리, *천문* 의 낭만이 약함.

## 추천

- **1차 추천: 안건 B (천문 삼각측량)** — 책 스토리 직결, 코사인 법칙의 *놀라움* 을 가장 잘 전달. 단원 5(사인)에서 구축한 단위원 자산을 사이드 위젯으로 곁들임.
