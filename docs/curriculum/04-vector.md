# 벡터 — 심술궂은 제트기류

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 벡터 — *심술궂은 제트기류* |
| **스토리 요약** | (※ 원문 확인 필요) 비행기가 목적지로 가려는데 *제트기류* 가 옆으로 밀어 항로가 어긋남. "내가 가려는 방향" 과 "흘러가는 방향" 이 다름 — 두 화살표의 합 = 벡터합. |
| **핵심 수학** | 벡터 성분 (x, y) · 크기·방향 · 합·차 · 분해 · 평행사변형 법칙 |

## 교과 맥락

- **한국 정규 교과**: 벡터 *식·기호* 는 **고2~고3** (기하 또는 미적분의 도구) ([나무위키 — 삼각함수](https://namu.wiki/w/%EC%82%BC%EA%B0%81%ED%95%A8%EC%88%98) 외 다수)
- **초등·중학교**: *방향 + 크기* 라는 직관은 가능 (예: 일기예보 풍향, 지도 위 이동)
- **결론**: *식·성분* 은 어려움. *화살표 시각·조작* 으로 풀어내면 초등 가능. PhET 한국어 버전 존재.

## 학습 목표

1. 벡터 = *크기 + 방향* 을 동시에 가진 양
2. 두 화살표의 *끝과 끝* 을 이으면 합벡터
3. 한 벡터를 두 방향으로 *나누어* 볼 수 있다 (분해)

## 관련 사이트 내 퍼즐

- `river` — 강 건너기. **흐름 + 진행 = 합성 벡터** 의 가장 직접적 사례. 본 단원의 *전제 퍼즐*
- `knight` — 격자 위 (1,2)/(2,1) 변위 벡터들

## 수학퍼즐 후보 조사

### 후보 1 — 비행기 항로 시뮬 ✈️
- **퍼즐 정의**: 출발지 A → 목적지 B. 비행기의 *목표 방향 화살표* 와 *제트기류 화살표* 를 슬라이더로 조절. 실제 항로 = 두 화살표의 합. 목적지에 도달하려면 사전 보정 필요.
- **풀이 흐름**: 풍속 표시 → 비행기 방향 조절 → 시뮬 재생 → 도착 확인
- **선례**: TeachEngineering [Vector Voyage!](https://www.teachengineering.org/activities/view/cub_navigation_lesson02_activity1) 가 *바람·해류* 까지 포함한 동일 컨셉. middle school 검증. MIT Zero Robotics 도 같은 활동을 5~6학년 적용.
- **초등 적합성 ★★★**: 추천. *Vector Voyage!* 의 학술적 근거 + 책 스토리(제트기류) 100% 매칭. 4~6학년 가능. 화살표만 보면 됨, 식 불필요.

### 후보 2 — 화살표 합 퍼즐 ➡️➕➡️
- **퍼즐 정의**: 두 화살표 주어짐. *합벡터의 끝점* 을 클릭으로 추측. 정답이면 평행사변형이 그려져 시각 확인.
- **풀이 흐름**: 두 화살표 표시 → 끝점 클릭 → 평행사변형 + 정답
- **선례**: PhET 의 평행사변형 시각이 표준. 게임화는 우리가 추가.
- **초등 적합성 ★★★**: 추천. 클릭 한 번으로 핵심 학습. 4~6학년 가능. 공간 감각 키우기 좋음.

### 후보 3 — 줄다리기 균형 ⚖️
- **퍼즐 정의**: 한 점에 줄이 N개 묶여있고 각 줄을 다른 방향·세기로 끔. 합이 0이면 점이 안 움직임. 균형 만들기 미션.
- **풀이 흐름**: 화살표 N개 표시 → 마지막 한 개의 방향·길이 조절 → 합이 0
- **선례**: 직접 동일 게임 부재. *static equilibrium* 물리 lesson 의 변형.
- **초등 적합성 ★★**: 부분 적합. *결과* 는 직관적이나 "왜 그런 방향이어야 하나" 추론 어려움. 5~6학년 + 도움말. 어른 1회 도움이면 OK.

### 후보 4 — 보물섬 명령서 🗺️
- **퍼즐 정의**: "북쪽 3걸음, 동쪽 4걸음, 북동쪽 2걸음..." 명령을 따라가면 보물 위치. *최종 위치* 를 격자에 클릭.
- **풀이 흐름**: 명령 읽기 → 한 걸음씩 그리기 → 최종 위치 클릭 → 정답
- **선례**: Vector Voyage! 의 *dead reckoning* 활동의 게임화 변형 — 항해 명령으로 위치 찾기. 어린이용 *map activities* 와 결합.
- **초등 적합성 ★★★**: 추천. 보물찾기 스토리, 명령 따라하기, 격자 클릭 모두 3~6학년 친화. 화살표 명령 수만 조절하면 난이도 자유.

### 후보 5 — 강 건너기 보정 (river 자매) 🚣
- **퍼즐 정의**: 보트가 강을 *수직으로* 건너고 싶지만 강물이 옆으로 흐름. 보트 머리를 *몇 도 위로* 향해야 똑바로 건너지나?
- **풀이 흐름**: 강물 속도 표시 → 보트 속도·각도 조절 → 시뮬 재생 → 도착점 확인
- **선례**: 후보 1과 본질 같음. Vector Voyage! 가 *해류* 도 다룸. 사이트 내 `river` 퍼즐과 시너지.
- **초등 적합성 ★★**: 부분 적합. 보정 사고 필요. 5~6학년 + 도움말. *강 건너기* 자매 콘텐츠로 묶으면 학습 시너지.

### 후보 6 — 벡터 합 시간 제한 게임 ⏱️
- **퍼즐 정의**: 화면에 화살표 여러 개 등장. 정해진 시간(20·40·60초) 안에 *합벡터의 크기·방향* 을 답함. 정답 누적 점수.
- **풀이 흐름**: 시간 시작 → 화살표 보고 합 추정 → 입력 → 다음 라운드
- **선례**: [Physics Classroom Vector Guessing Game](https://www.physicsclassroom.com/interactive/vectors-and-projectiles/vector-guessing-game) 가 사실상 동일 게임. 가성비 검증.
- **초등 적합성 ★★**: 부분 적합. 시간 압박 + 추정 부담. 6학년~중1 권장. *시간 제한 없는 모드* 만 분리하면 ★★★.

### 후보 7 — 화살표 분해 도구 🔧
- **퍼즐 정의**: 임의 화살표를 *x방향·y방향 두 개* 로 자동 분해. 비스듬한 화살표를 그려보고 *x 성분이 얼마인지* 슬라이더로 맞히기.
- **풀이 흐름**: 화살표 그리기 → x·y 성분 슬라이더로 추측 → 정답
- **선례**: PhET 의 component view. *분해* 자체에 집중.
- **초등 적합성 ★**: 어려움. 좌표 성분 개념 + 추정 필요. 6학년~중1. *눈대중 게임* 으로는 즐겁긴 함.

## 수학의 원리 탭 구현 계획

### 핵심 개념 4개

1. **벡터는 화살표**
   - 직관: "여기서 저기로 얼마만큼"
   - 시각: 위치(점) vs 변위(화살표) 비교
   - 자가 점검: "온도 30도" 는 벡터인가? (아니다 — 방향 없음)

2. **두 화살표를 *이어* 붙이면 합**
   - 직관: 첫 화살표 끝에 두 번째 시작 → 처음~끝 직선
   - 같은 결과: 평행사변형의 대각선
   - 시각: 두 가지 그리기 방법을 같은 화면에 병치 (PhET 패턴)

3. **한 화살표를 *나누어* 보기 (분해)**
   - 직관: "북동쪽으로 5걸음 = 북쪽 ?걸음 + 동쪽 ?걸음"
   - 시각: 비스듬한 화살표 위에 *x·y 성분* 점선

4. **합이 0이면 균형**
   - 직관: 줄다리기, 비행기 정지 비행
   - 시각: 화살표 3개가 삼각형을 이루며 *원점으로 돌아옴*

### 시각화 자산
- `CoordPlane` 재사용
- **신규**: `Arrow` 컴포넌트 — 시작점·끝점·색·라벨 (단원 5·6·7에서도 재활용 가능)

### 자가 점검 질문
1. 동쪽 3 + 북쪽 4 의 합벡터 크기는? (=5)
2. 두 화살표가 정확히 반대 방향, 크기 같으면 합은? (=0)
3. 비스듬한 화살표를 *수평·수직* 으로 나누는 것을 무엇이라 하나? (=분해)
