# 벡터 — 심술궂은 제트기류

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 벡터 — *심술궂은 제트기류* |
| **스토리 요약** | (※ 원문 확인 필요) 비행기가 목적지로 가려는데 *제트기류* 가 옆에서 밀어 항로가 어긋나는 일화. "내가 가고 싶은 방향"과 "흘러가게 되는 방향"이 다르다 — 두 화살표의 합 = 벡터합. |
| **핵심 수학** | 벡터의 성분 표현 · 크기·방향 · 합·차 · 분해 · 평행사변형/삼각형 법칙 |
| **학습 목표** | ① 벡터 ≠ 단순 숫자: 크기와 방향을 동시에 가짐 ② 두 벡터의 합이 *합성된 운동·힘* 임을 체득 ③ 한 벡터를 두 방향으로 *분해* 하는 직관 |

## 관련 수학퍼즐 조사

### 사이트 내 연관 퍼즐
- `river` — 강 건너기. **흐름 + 진행 = 합성 벡터**의 가장 직접적 사례. 본 단원의 *전제 퍼즐*로 삼아도 좋음.
- `knight` — 격자 위 이동 ((1,2)/(2,1) 등의 변위 벡터들).
- `consecutive-node` — 그래프 위 위치, 약하게 연결.

### 외부 클래식 퍼즐·사례
- **비행기 + 바람** (책의 제트기류).
- **보트 + 강물** — 책의 강 건너기와 동일 구조.
- **줄다리기 / 힘의 합성** — 정역학.
- **항해의 *드리프트(편류)*** — 항해사가 보정해야 하는 양.
- **GPS 속도 벡터** — 일상의 벡터.
- **체스 기물의 이동 벡터** — 사이트 내 `knight`와 연결.

## 구현 안건

### 안건 A — 표준 하네스 (두 벡터의 합)
- **컨셉**: 좌표평면에 두 화살표 v₁, v₂ 를 슬라이더 또는 끝점 드래그로 정의 → 합 v₁+v₂ 가 평행사변형 법칙으로 자동 표시.
- **탐험기**: 합·차·스칼라곱(2v₁) 토글. *분해 모드*: 임의 벡터를 x·y 성분으로 분해 시각화.
- **퀴즈**: (1) v₁=(3,1), v₂=(1,2) 의 합? (2) 크기는? (3) 한 벡터를 30°·60° 두 방향으로 분해.
- **코딩 탭**: 벡터를 `(x, y)` 튜플로 표현, 합·크기 계산.
- **예상 공수**: 중 (드래그 UI + 평행사변형 렌더링).
- **장점**: 벡터의 모든 기초 연산을 한 페이지에서.
- **단점**: 책 스토리(제트기류)와 시각적으로 떨어짐.

### 안건 B — 비행기 항로 시뮬레이터
- **컨셉**: 출발지 A → 목적지 B. 비행기의 *목표 속도 벡터* 와 *제트기류 벡터* 를 슬라이더로 조절. 실제 항로(합벡터)가 어디로 가는지 애니메이션.
- **메인 동선**: 제트기류 변동(시간에 따라 방향 변화) 모드 → 사용자가 *선제적 보정 각도* 를 입력해 목적지에 도달하는 미션.
- **힌트**: 화면 하단에 v_비행기 + v_바람 = v_실제 화살표 도해 항상 표시.
- **레벨**: 직선 바람 → 회전 바람 → 강한 측풍 → 폭풍 회피.
- **예상 공수**: 중~대 (시뮬 + 레벨 디자인).
- **장점**: 책 스토리 100% 매칭, 벡터 합·분해를 미션으로 강제 학습.
- **단점**: 학습 효과가 *합* 위주에 집중, 벡터의 다른 측면(스칼라곱 등)은 약화.

### 안건 C — 줄다리기·힘의 합성 (정역학)
- **컨셉**: 한 점에 여러 줄(화살표)을 매고, 각 줄을 끄는 *세기·각도* 를 조절해 그 점이 *움직이지 않는 균형* 상태 만들기.
- **메인 동선**: 화살표 2개부터 시작, 점차 3·4·5개로 확장. 균형 = 합벡터 = 0.
- **시각효과**: 균형 깨지면 점이 합벡터 방향으로 미끄러짐 (실시간 피드백).
- **변형**: 도르래·경사면 등 고전 물리 문제로 확장.
- **예상 공수**: 중.
- **장점**: 합 = 0의 직관, 벡터의 *분해* 와 정확히 같은 사고. 물리와 직결.
- **단점**: 책 스토리(제트기류)와 거리 있음. 일부 학생에게 정역학은 추상적.

## 추천

- **1차 추천: 안건 B (비행기 항로)** — 책 스토리 직결 + 기존 `river` 퍼즐과의 *직관 다리* 역할. 페이지 상단에 "강 건너기 보러가기" 링크로 자매 콘텐츠화.
- **결합안**: B를 메인으로 하고 *분해 미니위젯* 을 사이드 패널로 추가 → 합·분해 모두 커버.
