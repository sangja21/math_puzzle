# 벡터 — 심술궂은 제트기류

## 개요

| 항목 | 내용 |
|------|------|
| **책 챕터** | 벡터 — *심술궂은 제트기류* |
| **스토리 요약** | (※ 원문 확인 필요) 비행기가 목적지로 가려는데 *제트기류* 가 옆으로 밀어 항로가 어긋난다. "내가 가려는 방향" 과 "흘러가는 방향" 이 다름 — 두 화살표의 합 = 벡터합. |
| **핵심 수학** | 벡터 성분 (x, y) · 크기·방향 · 합·차 · 분해 · 평행사변형 법칙 |

## 학습 목표

1. 벡터 = *크기 + 방향* 을 동시에 가진 양
2. 두 화살표의 *끝과 끝* 을 이으면 합벡터
3. 한 벡터를 두 방향으로 *나누어* 볼 수 있다 (분해)

## 관련 사이트 내 퍼즐

- `river` — 강 건너기. **흐름 + 진행 = 합성 벡터** 의 가장 직접적 사례. 본 단원의 *전제 퍼즐*
- `knight` — 격자 위 (1,2)/(2,1) 변위 벡터들

## 수학퍼즐 후보 조사

### 후보 1 — 비행기 항로 시뮬 ✈️
- **퍼즐 정의**: 출발지 A → 목적지 B. 비행기의 *목표 방향 화살표* 와 *제트기류 화살표* 를 슬라이더로 조절. 실제 항로 = 두 화살표의 합. 목적지에 정확히 도달하려면 사전 보정 필요.
- **풀이 흐름**: 풍속 표시 → 비행기 방향 조절 → 시뮬 재생 → 도착 확인
- **핵심 수학**: 벡터 합, 보정 각도 = 분해의 역
- **초등학생 적합성 ★★**: 부분 적합. 화살표 *눈으로* 보면 직관적이나 "보정해야 한다" 는 추론은 5~6학년 + 도움말 필요. 단순 *발사 미션* 모드면 ★★★.

### 후보 2 — 화살표 합 퍼즐 ➡️➕➡️
- **퍼즐 정의**: 두 화살표가 주어짐. 사용자는 *합벡터의 끝점* 이 어디일지 클릭으로 추측. 정답이면 평행사변형이 그려져 시각 확인.
- **풀이 흐름**: 두 화살표 표시 → 끝점 클릭 → 평행사변형 + 정답
- **핵심 수학**: 평행사변형 법칙, 끝과 끝 잇기
- **초등학생 적합성 ★★★**: 추천. *클릭 한 번* 으로 핵심 학습. 4~6학년 가능. 공간 감각 키우기에 좋음.

### 후보 3 — 줄다리기 균형 ⚖️
- **퍼즐 정의**: 한 점에 줄이 N개 묶여있고 각 줄을 *다른 방향·세기* 로 끈다. 합이 0이면 점이 안 움직임. 균형 만들기 미션.
- **풀이 흐름**: 화살표 N개 표시 → 사용자가 *마지막 한 개* 의 방향·길이 조절 → 합이 0이 되도록
- **핵심 수학**: 합이 0 = 균형, 분해의 역
- **초등학생 적합성 ★★**: 부분 적합. *결과* 는 직관적이지만 "왜 그런 방향이어야 하나" 추론이 어려움. 5~6학년 가능, 어른 도움 한 번이면 OK.

### 후보 4 — 보물섬 명령서 🗺️
- **퍼즐 정의**: "북쪽 3걸음, 동쪽 4걸음, 북동쪽 2걸음..." 명령을 따라가면 보물 위치. 사용자는 *최종 위치* 를 격자에 클릭.
- **풀이 흐름**: 명령 읽기 → 한 걸음씩 그리기 → 최종 위치 클릭 → 정답
- **핵심 수학**: 변위의 누적 = 벡터 합
- **초등학생 적합성 ★★★**: 추천. 보물찾기 스토리, 명령 따라하기, 격자 클릭 모두 *3~6학년* 친화. 화살표 명령 수만 조절하면 난이도 자유.

### 후보 5 — 강 건너기 보정 (river 자매) 🚣
- **퍼즐 정의**: 보트가 강을 *수직으로* 건너고 싶지만 강물이 옆으로 흐름. 보트 머리를 *몇 도 위로* 향해야 똑바로 건너지나?
- **풀이 흐름**: 강물 속도 표시 → 보트 속도·각도 조절 → 시뮬 재생 → 도착점 확인
- **핵심 수학**: 분해, 합벡터가 수직이 되는 조건
- **초등학생 적합성 ★★**: 부분 적합. 후보 1과 본질 같음 — 보정 사고 필요. 5~6학년 + 도움말. 사이트 내 `river` 퍼즐 자매로 묶으면 학습 시너지.

### 후보 6 — 화살표 분해 도구 🔧
- **퍼즐 정의**: 임의 화살표를 *x방향·y방향 두 개* 로 자동 분해해 보여줌. 사용자는 비스듬한 화살표를 그려보고 *x 성분이 얼마인지* 슬라이더로 맞추기.
- **풀이 흐름**: 화살표 그리기 → x·y 성분 슬라이더로 추측 → 정답 표시
- **핵심 수학**: 분해, 직각 성분
- **초등학생 적합성 ★**: 어려움. 좌표 성분 개념 + 추정 필요. 6학년~중1 정도. *눈대중 게임* 으로 즐겁긴 함.

## 수학의 원리 탭 구현 계획

### 핵심 개념 4개

1. **벡터는 화살표**
   - 직관: "여기서 저기로 얼마만큼"
   - 시각: 위치(점) vs 변위(화살표) 비교
   - 자가 점검: "온도 30도" 는 벡터인가? (아니다 — 방향 없음)

2. **두 화살표를 *이어* 붙이면 합**
   - 직관: 첫 화살표 끝에 두 번째 화살표 시작 → 처음~끝 직선
   - 같은 결과: 평행사변형의 대각선
   - 시각: 두 가지 그리기 방법을 같은 화면에 병치

3. **한 화살표를 *나누어* 보기 (분해)**
   - 직관: "북동쪽으로 5걸음 = 북쪽 ?걸음 + 동쪽 ?걸음"
   - 시각: 비스듬한 화살표 위에 *x·y 성분* 점선

4. **합이 0이면 균형**
   - 직관: 줄다리기, 비행기 정지 비행
   - 시각: 화살표 3개가 삼각형을 이루며 *원점으로 돌아옴*

### 시각화 자산
- `CoordPlane` 재사용
- **신규**: `Arrow` 컴포넌트 — 시작점·끝점·색·라벨 (단원 5·6·7에서도 재활용 가능)

### 자가 점검 질문
1. 동쪽 3 + 북쪽 4 의 합벡터 크기는? (=5)
2. 두 화살표가 정확히 반대 방향, 크기 같으면 합은? (=0)
3. 비스듬한 화살표를 *수평·수직* 으로 나누는 것을 무엇이라 하나? (=분해)
