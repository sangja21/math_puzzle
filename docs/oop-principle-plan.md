# 코딩의 원리 - 객체지향(OOP) 구현 계획서

## 개요
- **경로**: `/coding/oop`
- **카테고리**: 코딩의 원리 → 객체지향 파트
- **학습 목표**: "데이터 + 동작의 묶음"이라는 객체의 핵심 직관을 체험으로 먼저 잡기
- **핵심 비유**: 체스 기물 — 킹, 퀸, 룩, 비숍, 나이트, 폰은 모두 **이름, 색깔, 위치**라는 같은 구조를 가지지만, **이동 방식(메서드)은 각자 다르다**

## 탭 구성 (3단계)

---

### 탭 1: 🎮 객체란? (Object)

**목적**: "기물 하나 = 속성 + 동작이 묶인 객체"

**인터랙티브 데모**:
- 체스 기물 5종 카드 (♟ 폰, ♞ 나이트, ♝ 비숍, ♜ 룩, ♛ 퀸)
- 카드를 클릭하면 **속성(Attributes)** 펼쳐짐:
  - 이름, 색깔, 현재 위치, 이동 방식 설명
- 오른쪽 미니 체스판(5×5)에 해당 기물 배치 → **"이동!" 버튼** 클릭 시 이동 가능한 칸이 파란색으로 하이라이트
- 코드 블록 미리보기:
  ```
  knight = {
    name: "나이트",
    color: "white",
    position: "d4",
    move: L자 이동()
  }
  ```
- **핵심 메시지**: "기물 하나가 속성 + 동작을 가진 하나의 객체(Object)예요!"

---

### 탭 2: 🏭 클래스와 인스턴스 (Class & Instance)

**목적**: "클래스 = 기물 설계도, 인스턴스 = 실제 말"

**인터랙티브 데모**:
- 왼쪽: **ChessPiece 클래스 설계도** (빈 슬롯들)
  - 이름: [선택▼] (폰/나이트/비숍/룩/퀸)
  - 색깔: [⬜ 흰색 / ⬛ 검정색]
  - 위치: [체스판 클릭으로 선택]
- "기물 만들기 🏭" 버튼 → 오른쪽 미니 체스판에 기물 배치
- 최대 4개까지 직접 만들어 배치 가능
- 각 기물 클릭 시 속성 카드 표시 (같은 클래스, 다른 인스턴스)
- 코드 미리보기:
  ```
  class ChessPiece:
      def __init__(name, color, position):
          self.name = name
          self.color = color
          self.position = position

  # 인스턴스 생성
  piece1 = ChessPiece("나이트", "white", "d4")
  piece2 = ChessPiece("룩",    "black", "a1")
  ```
- **핵심 메시지**: "같은 설계도(클래스)로 여러 기물(인스턴스)을 찍어낼 수 있어요! 마치 붕어빵 틀처럼!"

---

### 탭 3: 🧬 상속 + 추상화 (Inheritance & Abstraction)

**목적**: "공통 틀을 물려주되, 구체적인 구현은 자식이 결정한다"

**인터랙티브 데모**:
- 화면 상단: **ChessPiece 추상 클래스** 카드 (회색/점선 테두리로 "추상" 느낌)
  - 공통 속성: name, color, position
  - 공통 메서드: capture() — 이건 구현되어 있음 (잡기는 모두 같으므로)
  - 추상 메서드: move() — ❓ 표시 (내용 없음, "자식이 채워야 함")
  - "ChessPiece만으로는 기물을 만들 수 없어요!" 안내
- 아래에 자식 클래스 3개가 선으로 연결된 트리:
  - **Rook**: move() = 직선 이동 ↑↓←→
  - **Bishop**: move() = 대각선 이동 ↗↘↙↖
  - **Queen**: move() = 직선 + 대각선 (룩 + 비숍 합체!)
- 부모 카드의 속성/메서드를 클릭하면 자식 카드에서도 해당 부분 하이라이트 (상속 시각화)
- 오른쪽 미니 체스판: 자식 클래스 선택 → 각자의 move()로 이동 가능 칸 표시
- 코드 미리보기:
  ```
  class ChessPiece:          # 추상 부모
      name, color, position
      def capture(): ...     # 공통 구현
      def move(): ???        # 추상 메서드 — 자식이 구현!

  class Rook(ChessPiece):    # 자식 (상속)
      def move(): 직선 이동

  class Bishop(ChessPiece):
      def move(): 대각선 이동

  class Queen(ChessPiece):   # 룩 + 비숍의 능력을 모두!
      def move(): 직선 + 대각선
  ```
- **핵심 메시지 1 (상속)**: "퀸은 왜 가장 강할까요? 룩과 비숍의 이동 능력을 모두 물려받았기 때문이에요!"
- **핵심 메시지 2 (추상화)**: "move()라는 이름은 같지만, 기물마다 실제 동작이 달라요 — 이게 추상화예요!"

## 체스 기물 이동 규칙 (미니보드 구현용)

| 기물 | 이동 규칙 |
|------|----------|
| 폰 ♟ | 앞으로 1칸 (첫 이동 시 2칸) |
| 나이트 ♞ | L자 (2+1칸) |
| 비숍 ♝ | 대각선 무제한 |
| 룩 ♜ | 직선 무제한 (상하좌우) |
| 퀸 ♛ | 직선 + 대각선 무제한 |
